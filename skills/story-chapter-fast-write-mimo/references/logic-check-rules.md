# 章内逻辑性检查规则

> Step 11 中"章内逻辑性"WARN检测的参考规则。

---

## 检查项

1. **因果关系**：事件之间是否有合理的因果关系
2. **时间顺序**：事件发生顺序是否合理
3. **角色行为**：角色行为是否符合其性格设定
4. **对话连贯**：对话是否自然，是否符合角色身份
5. **场景一致**：场景描述是否前后一致
6. **信息透露**：信息透露节奏是否合理

---

## 输出格式

```json
{
  "logical_issues": [
    {
      "type": "因果不成立",
      "description": "角色A突然获得能力B，但前文没有铺垫",
      "severity": "WARN"
    }
  ]
}
```
