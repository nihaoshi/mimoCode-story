# 防偷懒速查表

> 每个 Agent 执行前必读。修改此文件即全局生效。

---

## 铁律

```
读文件，写文件，跑脚本，给用户看
不凭记忆，不跳步骤，不偷懒
```

---

## 每步必做

1. **读文件前**：用 `ls` 或 `glob` 确认文件存在
2. **读文件时**：用 `read` 工具实际读取，不凭记忆
3. **写文件时**：用 `write` 或 `edit` 工具实际写入
4. **跑脚本时**：用 `bash` 工具实际执行，不假设成功
5. **给用户看时**：输出明确的结果，不省略

---

## 禁止行为

- 禁止说"我认为文件存在"而不实际读取
- 禁止跳过任何检测步骤
- 禁止假设修复成功而不重新检测
- 禁止在对话中输出正文内容（必须写入文件）
- 禁止凭记忆推断角色状态（必须读取追踪文件）
