# project-health-mimo：项目健康检查与修复

你是项目健康检查专家。检测写作项目的所有必需文件是否齐全，自动修复缺失文件。

---

## 触发条件

| 用户说 | 动作 |
|--------|------|
| /project-health-mimo | 检查当前项目 |
| /project-health-mimo <项目目录> | 检查指定项目 |
| /project-health-mimo --fix | 检查并修复 |
| 检查项目 | 同 /project-health-mimo |
| 修复项目 | 同 /project-health-mimo --fix |
| 检查文件 | 同 /project-health-mimo |

---

## 必需文件清单

### 一级文件（必须存在）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `AGENTS.md` | Writing Project Rules | AI无法自动读取写作规则 |
| `.story-deployed` | 部署标记 | 无法判断项目是否已初始化 |
| `.active-book` | 当前书目标记 | 多书项目无法切换 |

### 设定目录（设定/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `设定/世界观/背景设定.md` | 世界观设定 | 世界观不完整 |
| `设定/世界观/金手指.md` | 金手指规则 | 金手指机制不明 |
| `设定/角色/{角色名}.md` | 角色设定 | 角色人设缺失 |
| `设定/势力/{势力名}.md` | 势力设定 | 势力关系不明 |
| `设定/关系.md` | 角色关系 | 关系网缺失 |
| `设定/题材定位.md` | 题材与目标读者 | 写作方向不明确 |
| `设定/文风.md` | 文风约束 | 文风不一致 |

### 大纲目录（大纲/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `大纲/大纲.md` | 全书卷级大纲 | 无法把握全书结构 |
| `大纲/卷纲_第X卷.md` | 每卷详细大纲 | 无法规划卷级节奏 |

### 追踪目录（追踪/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `追踪/上下文.md` | 进度摘要 | 跨会话无法恢复 |
| `追踪/伏笔.md` | 伏笔追踪 | 伏笔遗漏 |
| `追踪/角色状态.md` | 角色状态 | 角色不一致 |
| `追踪/时间线.md` | 事件时间线 | 时间混乱 |
| `追踪/物品.md` | 物品追踪 | 物品位置矛盾 |
| `追踪/环境.md` | 环境追踪 | 环境描述矛盾 |
| `追踪/物资.md` | 物资追踪 | 经济状态不明 |
| `追踪/重复语句.md` | 重复语句黑名单 | 重复表达 |

### 故事线目录（故事线/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `故事线/故事线_索引.md` | 故事线列表+状态 | 主线/支线不明 |
| `故事线/故事线_主线_*.md` | 主线故事线 | 主线进展丢失 |
| `故事线/故事线_交叉点.md` | 线与线交汇 | 交叉点遗漏 |

### 跨卷追踪目录（跨卷追踪/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `跨卷追踪/跨卷伏笔.md` | 跨卷伏笔 | 长线伏笔遗漏 |
| `跨卷追踪/跨卷角色弧线.md` | 角色全书成长 | 角色弧线断裂 |
| `跨卷追踪/卷间过渡.md` | 卷与卷衔接 | 过渡不自然 |

### 正文目录（正文/）

| 文件 | 用途 | 缺失影响 |
|------|------|---------|
| `正文/第XXX章_章名.md` | 章节文件 | 无正文内容 |

## 执行流程

### Step 1：检测项目结构

```bash
node skills/project-health-mimo/scripts/project-health.js <项目目录> --check
```

### Step 2：输出检测报告

```
🔍 项目健康检查报告

📊 项目：{项目名}
📁 状态：{健康/需修复}

✅ 已存在：
- AGENTS.md
- .story-deployed
- 设定/世界观/背景设定.md
- ...

❌ 缺失：
- 设定/关系.md
- 追踪/时间线.md
- ...

⚠️ 警告：
- 设定/角色/ 目录为空
- 大纲/ 目录缺少卷纲
```

### Step 3：自动修复（--fix 模式）

```bash
node skills/project-health-mimo/scripts/project-health.js <项目目录> --fix
```

**修复内容**：
1. 创建缺失目录
2. 创建缺失文件（使用默认模板）
3. 初始化追踪文件
4. 更新 .story-deployed 标记

### Step 4：输出修复报告

```
🔧 项目修复完成

✅ 已创建：
- 设定/关系.md（空模板）
- 设定/题材定位.md（空模板）
- 追踪/时间线.md（空模板）
- ...

📝 下一步：
- 填充设定文件内容
- 开始写作
```

## 检查项详细说明

### 文件完整性检查

| 检查项 | 检查方法 |
|--------|---------|
| 文件存在 | fs.existsSync() |
| 文件非空 | fs.statSync().size > 0 |
| 格式正确 | 检查 markdown 格式 |

### 目录结构检查

| 目录 | 必需子目录 |
|------|-----------|
| 设定/ | 世界观/、角色/、势力/ |
| 大纲/ | - |
| 正文/ | - |
| 追踪/ | - |
| 故事线/ | - |
| 跨卷追踪/ | - |

### 内容完整性检查

| 文件 | 必需内容 |
|------|---------|
| 角色状态.md | 至少一个角色 |
| 伏笔.md | 表格格式 |
| 时间线.md | 表格格式 |
| 上下文.md | 当前进度 |
| 角色/ 角色设定 | 与追踪/角色状态.md 互相印证（character-sync.js） |
