# 对话质量检查清单

> 写完对话后，用这个清单自检。

---

## 基础检查

- [ ] 每句对话都有动作/表情
- [ ] 对话标签简洁（"他说""她说"）
- [ ] 避免"说道""问道""叹道"等冗余标签
- [ ] 对话符合角色性格
- [ ] 对话符合场景氛围

---

## 节奏检查

- [ ] 紧张场景用短句
- [ ] 缓冲场景用长句
- [ ] 有打断、沉默、转移话题
- [ ] 不是所有话都说完了
- [ ] 有留白让读者想象

---

## 潜台词检查

- [ ] 不是所有话都直说
- [ ] 有言外之意
- [ ] 有话里有话
- [ ] 有故意说反话
- [ ] 有欲言又止

---

## 信息控制检查

- [ ] 不是信息倾倒
- [ ] 分层次传递信息
- [ ] 用反应展示信息的重要性
- [ ] 有信息差制造悬念
- [ ] 有伏笔和呼应

---

## 情感检查

- [ ] 用动作表达情感
- [ ] 用环境烘托情感
- [ ] 有情感层次（不是单一情绪）
- [ ] 有情感转折
- [ ] 有情感余韵

---

## 遮名测试

- [ ] 遮住名字能分辨谁在说话
- [ ] 每个角色的说话方式不同
- [ ] 有口头禅/习惯用语
- [ ] 有语气差异
- [ ] 有表达方式差异

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 对话太书面化 | 改成口语，加入语气词 |
| 对话太啰嗦 | 精简，删掉不必要的解释 |
| 对话太平淡 | 加入冲突、转折、潜台词 |
| 对话太刻意 | 加入打断、沉默、转移 |
| 角色声音相同 | 为每个角色设计独特的说话方式 |
