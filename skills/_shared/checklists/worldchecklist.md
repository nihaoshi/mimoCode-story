# 世界观检查清单

> 构建世界观后，用这个清单自检。

---

## 基础检查

- [ ] 有明确的时代背景
- [ ] 有核心规则
- [ ] 有力量体系（如适用）
- [ ] 有地理分布
- [ ] 有势力设定

---

## 一致性检查

- [ ] 规则前后一致
- [ ] 力量体系自洽
- [ ] 地理分布合理
- [ ] 势力关系合理
- [ ] 没有矛盾/漏洞

---

## 完整性检查

- [ ] 覆盖主要区域
- [ ] 覆盖主要势力
- [ ] 覆盖主要规则
- [ ] 有足够的细节
- [ ] 留有探索空间

---

## 合理性检查

- [ ] 规则符合逻辑
- [ ] 力量有代价
- [ ] 地理有特色
- [ ] 势力有动机
- [ ] 整体可信

---

## 展示检查

- [ ] 通过故事展示设定
- [ ] 不是"设定课"
- [ ] 有具体例子
- [ ] 有角色视角
- [ ] 有生活细节

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 设定太复杂 | 精简，只保留必要的 |
| 设定太简单 | 增加细节和层次 |
| 设定不一致 | 检查前后矛盾 |
| 设定太刻意 | 通过故事自然展示 |
| 设定不可信 | 增加逻辑和代价 |
