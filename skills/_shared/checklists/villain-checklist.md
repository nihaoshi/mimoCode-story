# 反派设计检查清单

> 设计反派后，用这个清单自检。

---

## 基础检查

- [ ] 有明确的身份/地位
- [ ] 有强大的实力/能力
- [ ] 有核心动机
- [ ] 有独特的性格特质
- [ ] 有弱点/缺陷

---

## 动机检查

- [ ] 动机要合理（不是"纯恶"）
- [ ] 动机有层次（表面动机 vs 深层动机）
- [ ] 动机有故事（为什么会有这个动机）
- [ ] 动机有逻辑（能自圆其说）
- [ ] 动机有重量（让读者理解/同情）

---

## 出场检查

- [ ] 出场有压迫感
- [ ] 出场有记忆点
- [ ] 出场有反差（预期 vs 实际）
- [ ] 出场有伏笔
- [ ] 出场有张力

---

## 冲突检查

- [ ] 与主角有核心冲突
- [ ] 冲突有层次（不是单一冲突）
- [ ] 冲突有升级
- [ ] 冲突有解决
- [ ] 冲突有代价

---

## 成长检查

- [ ] 反派有成长弧线
- [ ] 反派有改变
- [ ] 反派有选择
- [ ] 反派有代价
- [ ] 反派有结局

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 反派太脸谱化 | 增加背景故事和动机 |
| 反派太弱 | 增加实力/智谋/资源 |
| 反派太强 | 增加弱点/限制 |
| 反派无趣 | 增加反差/复杂性 |
| 反派不可信 | 让动机合理/有逻辑 |
