# 情感线检查清单

> 设计情感线后，用这个清单自检。

---

## 结构检查

- [ ] 有明确的起点（相识）
- [ ] 有发展过程（相知）
- [ ] 有冲突/转折（误会/分离）
- [ ] 有结局（和好/分离/开放）
- [ ] 整体弧线完整

---

## 节奏检查

- [ ] 不是"一见钟情"（除非有特别设计）
- [ ] 有情感升温的过程
- [ ] 有冲突制造张力
- [ ] 有高潮释放情感
- [ ] 有余韵延续情绪

---

## 细节检查

- [ ] 用细节表达情感（动作、表情、习惯）
- [ ] 有专属两人的默契/暗号
- [ ] 有情感锚点（物品、地点、场景）
- [ ] 有情感对比（过去 vs 现在）
- [ ] 有情感递进（从浅到深）

---

## 冲突检查

- [ ] 冲突要合理（不是故意制造矛盾）
- [ ] 冲突有重量感
- [ ] 冲突有层次（不是单一冲突）
- [ ] 冲突有解决方式
- [ ] 冲突有成长/改变

---

## 人物检查

- [ ] 两个角色都有独立的性格
- [ ] 两个角色都有成长弧线
- [ ] 情感是双向的（不是单方面）
- [ ] 有各自的弱点和缺陷
- [ ] 有互补或相似的地方

---

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 情感发展太快 | 增加中间过程，用细节展示 |
| 情感太假 | 用具体事件，不要空洞抒情 |
| 冲突太刻意 | 让冲突源于性格/处境，而非误会 |
| 结局太仓促 | 增加余韵，留白让读者回味 |
| 角色脸谱化 | 给角色增加缺点和成长 |
