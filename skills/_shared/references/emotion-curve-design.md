# 情绪曲线设计

> 网文节奏的核心不是"发生了什么事"，而是"读者感受到什么情绪"。本文档提供情绪曲线的设计方法、检测规则和修复技巧。

---

## 核心原则

1. **情绪必须有起伏**。连续 3 段相同强度的同类情绪 = 读者疲劳。
2. **波峰波谷交替**。高压段后必须有释放，低压段后必须有升级。
3. **情绪服务于爽点**。爽点的本质是"压制后的释放"，没有压制就没有爽感。

---

## 情绪曲线基本模型

### V 型曲线（最低配）

```
情绪
  │
高│        ╱╲
  │       ╱  ╲
  │      ╱    ╲
低│─────╱      ╲─────
  └──────────────────→ 篇幅
    铺垫  压制  释放
```

适用：单章短篇、日常装逼场景。

### W 型曲线（标准配置）

```
情绪
  │
高│    ╱╲      ╱╲
  │   ╱  ╲    ╱  ╲
  │  ╱    ╲  ╱    ╲
低│─╱      ╲╱      ╲─
  └──────────────────→ 篇幅
    小爽  低谷  大爽
```

适用：标准章节、多事件章节。

### 递进型曲线（长线配置）

```
情绪
  │              ╱╲
  │           ╱╲╱  ╲
  │        ╱╲╱      ╲
  │     ╱╲╱          ╲
  │  ╱╲╱              ╲
低│─╱                  ╲─
  └──────────────────────→ 篇幅
    每次低谷更深，每次高峰更高
```

适用：逆袭文、成长文、追妻火葬场。

### 延迟满足型曲线

```
情绪
  │
  │                    ╱──
  │                   ╱
  │                  ╱
  │                 ╱
低│────────────────╱
  └──────────────────────→ 篇幅
    长时间低压，最后爆发
```

适用：虐文触底反弹、悬疑揭秘、最终决战。

## 按题材的情绪模板

| 题材 | 曲线类型 | 核心节奏 | 低谷占比 | 高峰占比 |
|------|---------|---------|---------|---------|
| 打脸/逆袭 | 递进型 | 低→更低→触底→爆 | 60% | 40% |
| 身份反转 | W型 | 小爽→危机→大爽 | 40% | 60% |
| 虐文/意难平 | 延迟满足 | 持续低→最后一爆 | 80% | 20% |
| 悬疑/惊悚 | 递进型 | 好奇→紧张→恐惧→揭秘 | 50% | 50% |
| 日常装逼 | V型 | 平静→小冲突→打脸 | 30% | 70% |
| 甜宠/恋爱 | W型 | 相遇→误会→和好→撒糖 | 40% | 60% |

## 章节级情绪标注方法

### 标注格式

在细纲中标注每章的情绪目标：

```markdown
### 第15章：绝地反击

**情绪目标**：压制→爆发（V型）
**情绪强度**：低谷 3/10 → 高峰 9/10
**爽点位置**：章末 80%
**压制手段**：主角被诬陷、众人误解
**释放方式**：证据公开、众人震惊
```

### 情绪强度标尺

| 强度 | 情绪状态 | 读者反应 |
|------|---------|---------|
| 1-2 | 平静、日常 | 轻松阅读 |
| 3-4 | 好奇、期待 | 想继续看 |
| 5-6 | 紧张、担心 | 刷屏式阅读 |
| 7-8 | 愤怒、心痛 | 想打人/想哭 |
| 9-10 | 震撼、爽爆 | 拍桌子/截图分享 |

## 连续平坦检测与修复

### 检测规则

连续 3 章情绪强度波动 < 2 点 → 触发"平坦警告"。

**示例**：
- 第10章：强度 5 → 第11章：强度 5 → 第12章：强度 6 → ⚠️ 平坦
- 第10章：强度 3 → 第11章：强度 7 → 第12章：强度 4 → ✅ 正常

### 修复方法

| 平坦类型 | 症状 | 修复方案 |
|---------|------|---------|
| 持续低压 | 3章都在强度 3-4 | 插入一个小爽点（打脸/意外收获） |
| 持续高压 | 3章都在强度 7-8 | 插入一个喘息段（日常/回忆/对话） |
| 情绪同质 | 3章都是"紧张" | 切换情绪类型（紧张→愤怒→释放） |
| 无低谷 | 一直爽没压制 | 增加一个危机/反转，制造低谷 |
| 无高峰 | 一直平淡没爆点 | 增加一个爽点/揭秘，制造高峰 |

## 爽点与情绪的关系

### 爽点公式

```
爽感 = 压制强度 × 释放速度 × 读者预期差
```

- **压制越深，爽感越强**（但不能超过读者忍耐极限）
- **释放越快，爽感越强**（但不能太突兀）
- **预期差越大，爽感越强**（但必须有铺垫）

### 爽点间距

| 题材 | 建议间距 | 最大容忍间距 |
|------|---------|------------|
| 番茄/短篇 | 每 1500-2000 字 | 3000 字 |
| 起点/长篇 | 每 3000-5000 字 | 8000 字 |
| 晋江/言情 | 每 2000-3000 字 | 5000 字 |
| 悬疑/惊悚 | 每 2000-4000 字 | 6000 字 |

超过最大容忍间距 → 读者流失风险显著上升。

## 与 review skill 的集成

story-review-mimo 的"结构审查"维度应检查：

1. 情绪曲线是否有起伏（不平坦）
2. 压制-释放比例是否合理
3. 爽点间距是否在建议范围内
4. 章尾情绪是否留有余韵（不总结升华）
5. 连续 3 章是否有情绪切换
