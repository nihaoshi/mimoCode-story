# 版本管理系统

> 版本：1.0.0
> 更新时间：2026-06-12
> 目标：版本管理零成本

---

## 概述

利用Git实现写作内容的版本管理，支持回溯、对比、恢复。

---

## 版本管理策略

| 内容 | 管理方式 | 触发时机 | 保留策略 |
|------|---------|---------|---------|
| 正文 | Git自动提交 | 每章写完后 | 永久保留 |
| 追踪文件 | Git自动提交 | 每章写完后 | 永久保留 |
| 大纲/细纲 | Git手动提交 | 修改后 | 永久保留 |
| 设定文件 | Git手动提交 | 修改后 | 永久保留 |

---

## Git配置

### 自动提交格式

```
commit message: Ch{N}: {章名} ({字数}字)
files: 正文/第{N}章_{章名}.md, 追踪/*.md
```

### 标签格式

```
tag: vol{X}-end (第{X}卷结束)
tag: ch{N} (关键章节标记)
```

---

## 自动化流程

### 1. 每章写完后自动提交

```bash
# 在workflow-daily.md Step 2每章写完后执行
git add 正文/第{N}章_*.md 追踪/*.md
git commit -m "Ch{N}: {章名} ({字数}字)"
```

### 2. 每卷结束时自动打标签

```bash
# 在卷结束时执行
git tag vol{X}-end
git push --tags
```

### 3. 每50章归档时自动提交

```bash
# 在归档时执行
git add 追踪/归档/
git commit -m "归档：第{A}-{B}章追踪文件"
```

## 回溯能力

### 查看某章历史版本

```bash
git log --oneline 正文/第{N}章_*.md
git show {commit_hash}:正文/第{N}章_*.md
```

### 对比两章差异

```bash
git diff {commit1} {commit2} -- 正文/
```

### 回退到某章

```bash
git checkout {commit_hash} -- 正文/第{N}章_*.md
```

### 回退整个卷

```bash
git checkout vol{X}-end -- 正文/ 追踪/
```
