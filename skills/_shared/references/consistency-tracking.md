# 长文一致性追踪系统

> 版本：1.0.0
> 更新时间：2026-06-12

---

## 概述

长文写作中，细节连续性是质量的关键。本系统通过多维度追踪，确保：
- 物品位置、状态连续
- 角色穿衣、身体状态连续
- 环境（季节、天气、场景）连续
- 伏笔、时间线连续
- 经济状态连续

---

## 追踪维度

### 核心维度（必须追踪）

| 维度 | 文件 | 追踪内容 | 更新频率 | 重要性 |
|------|------|---------|---------|--------|
| **伏笔** | `追踪/伏笔.md` | 剧情伏笔、状态、紧迫度 | 每章 | 高 |
| **时间线** | `追踪/时间线.md` | 事件时序、季节、时间 | 每章 | 高 |
| **角色状态** | `追踪/角色状态.md` | 身份、能力、关系、穿衣、身体 | 每章 | 高 |
| **物品** | `追踪/物品.md` | 关键物品位置、状态 | 每章 | 高 |
| **环境** | `追踪/环境.md` | 季节、天气、场景位置 | 每章 | 高 |

### 辅助维度（按需追踪）

| 维度 | 文件 | 追踪内容 | 更新频率 | 重要性 |
|------|------|---------|---------|--------|
| **经济/物资** | `追踪/物资.md` | 钱财、食物、工具 | 按需 | 中 |
| **身体状态** | `追踪/角色状态.md`子项 | 健康、伤势、疲劳 | 每章 | 中 |
| **穿衣** | `追踪/角色状态.md`子项 | 角色穿着变化 | 每章 | 中 |

## 更新流程

### 写完每章后必须更新

```
1. 伏笔.md
   - 新增伏笔（如本章埋设新伏笔）
   - 回收伏笔（如本章回收旧伏笔）
   - 更新紧迫度

2. 时间线.md
   - 记录本章事件时序
   - 更新季节/时间

3. 角色状态.md
   - 更新角色身份变化
   - 更新角色穿衣变化
   - 更新角色身体状态
   - 更新角色物品位置
   - 更新角色关系变化

4. 物品.md
   - 更新物品位置变化
   - 更新物品状态变化
   - 新增物品（如本章获得新物品）

5. 环境.md
   - 更新季节/天气
   - 更新场景位置
   - 更新环境细节

6. 上下文.md
   - 更新进度摘要
```

### 写新章前必须检查

```
1. 物品连续性
   - 关键物品在哪？
   - 物品状态如何？
   - 物品该出现吗？

2. 穿衣连续性
   - 角色现在穿什么？
   - 该换衣服了吗？
   - 穿衣符合场景吗？

3. 环境连续性
   - 现在是什么季节？
   - 现在是什么天气？
   - 角色在哪？
   - 环境符合时间线吗？

4. 身体连续性
   - 角色有没有受伤？
   - 疲劳程度如何？
   - 身体状态符合情节吗？

5. 伏笔状态
   - 哪些伏笔需要回收？
   - 哪些伏笔需要推进？
   - 本章该埋设新伏笔吗？

6. 经济状态
   - 角色有多少钱？
   - 该花钱吗？
   - 经济压力如何？
```

## 质量检查清单

### 一致性检查

| 检查项 | 检查方法 | 通过标准 |
|--------|---------|---------|
| 物品连续性 | 对照物品.md | 物品位置、状态无矛盾 |
| 穿衣连续性 | 对照角色状态.md | 穿衣变化合理 |
| 环境连续性 | 对照环境.md | 季节、天气、位置无矛盾 |
| 身体连续性 | 对照角色状态.md | 身体状态无矛盾 |
| 伏笔连续性 | 对照伏笔.md | 伏笔状态无矛盾 |
| 经济连续性 | 对照物资.md | 经济状态无矛盾 |

### 常见错误

| 错误类型 | 示例 | 预防方法 |
|----------|------|---------|
| 物品消失 | 白瓷片突然不见 | 每章检查物品位置 |
| 穿衣矛盾 | 冬天穿单衣 | 检查季节与穿衣 |
| 环境矛盾 | 夏天出现雪 | 检查季节与环境 |
| 身体矛盾 | 受伤后无痛感 | 检查身体状态 |
| 时间矛盾 | 一天内做太多事 | 检查时间线 |
| 经济矛盾 | 没钱却大手大脚 | 检查经济状态 |

## 千万字级别支持

### 分片机制

当项目超过 100 章时，启用分片机制：

```
追踪/
├── 伏笔.md                    # 当前卷活跃伏笔
├── 伏笔_索引.md               # 全书伏笔总索引
├── 伏笔_归档_第01-10卷.md     # 归档伏笔
├── 角色状态.md                # 当前卷活跃角色
├── 角色状态_索引.md           # 全书角色索引
├── 角色状态_归档_第01-10卷.md # 归档角色状态
├── 时间线.md                  # 主线时间线
├── 时间线_索引.md             # 时间线索引
├── 时间线_副线_{名}.md        # 副线时间线
├── 物品.md                    # 物品追踪
├── 环境.md                    # 环境追踪
├── 物资.md                    # 物资追踪
├── 上下文.md                  # 进度摘要
└── 归档/
    └── 第001-050章.md         # 上下文归档
```

### 五层摘要机制

| 层级 | 粒度 | 维护时机 |
|------|------|----------|
| **近3章详记** | 逐章详细摘要 | 每章写完后 |
| **10章概要** | 每10章一段 | 每10章生成 |
| **卷内总览** | 每卷一段详细总结 | 每卷结束时 |
| **卷间摘要** | 每卷一句话 | 每卷结束时 |
| **全书鸟瞰** | 全书核心进展 | 按需更新 |

### 分级一致性检查

| 检查级别 | 范围 | 触发时机 | 预计耗时 |
|----------|------|----------|----------|
| **增量检查** | 本次写作章节 | 每章/每批写完 | 即时 |
| **卷级检查** | 当前卷全部章节 | 每卷结束 | 分钟级 |
| **全局检查** | 全书 | `/story-review` | 小时级 |
| **伏笔审计** | 全部活跃伏笔 | 每50章 | 分钟级 |
