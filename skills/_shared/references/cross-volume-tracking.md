# 跨卷追踪

> 版本：1.0.0
> 更新时间：2026-06-12

---

## 概述

长篇小说通常包含多卷结构，需要跨卷追踪以下内容：
- 跨卷伏笔（需要多卷才能回收的伏笔）
- 跨卷角色弧线（角色在全书中的成长路线）
- 卷间过渡（卷与卷之间的衔接要点）

---

## 文件结构

```
跨卷追踪/
├── 跨卷伏笔.md               # 需要跨卷回收的伏笔
├── 跨卷角色弧线.md            # 角色全书成长路线
└── 卷间过渡.md               # 卷与卷衔接要点
```

```markdown
## 卷间过渡检查点

每卷结束时，检查：

1. **伏笔处理**：
   - 哪些伏笔需要在卷末回收？
   - 哪些伏笔需要带入下一卷？
   - 是否有新的跨卷伏笔需要埋设？

2. **角色状态**：
   - 主要角色的当前状态
   - 角色关系的变化
   - 角色弧线的进展

3. **环境/时间**：
   - 当前故事时间
   - 当前场景位置
   - 下一卷的时间/地点规划

4. **核心冲突**：
   - 本卷的核心冲突是否解决
   - 下一卷的核心冲突是什么
   - 冲突的升级/转换如何设计
```

## 管理流程

### 1. 跨卷伏笔管理

**埋设跨卷伏笔时**：
1. 在 `伏笔.md` 中记录伏笔信息
2. 在 `跨卷伏笔.md` 中记录跨卷回收计划
3. 标记预计回收的卷和章节

**每卷结束时**：
1. 检查本卷应回收的跨卷伏笔
2. 更新伏笔状态（已回收/继续潜伏/过期）
3. 规划下一卷的伏笔回收

### 2. 角色弧线管理

**每卷开始时**：
1. 读取 `跨卷角色弧线.md` 中的角色当前状态
2. 确认本卷的角色成长目标
3. 规划本卷的关键事件

**每卷结束时**：
1. 更新角色弧线的当前阶段
2. 记录本卷的状态变化
3. 规划下一卷的成长目标

### 3. 卷间过渡管理

**每卷结束前 5 章**：
1. 开始规划卷间过渡
2. 确认过渡要点
3. 准备过渡检查清单

**新卷开始时**：
1. 执行过渡检查清单
2. 确认所有过渡要点已处理
3. 开始新卷的写作

## 千万字级别支持

### 跨卷伏笔分片

当跨卷伏笔超过 50 条时，启用分片：

```
跨卷追踪/
├── 跨卷伏笔.md                 # 活跃跨卷伏笔
├── 跨卷伏笔_索引.md            # 全书跨卷伏笔索引
├── 跨卷伏笔_归档_第01-10卷.md  # 已回收的跨卷伏笔
└── ...
```

### 角色弧线分片

当角色超过 20 个时，启用分片：

```
跨卷追踪/
├── 跨卷角色弧线.md             # 主要角色弧线
├── 跨卷角色弧线_索引.md        # 全书角色弧线索引
├── 跨卷角色弧线_配角.md        # 配角弧线
└── ...
```

## 与追踪系统的集成

跨卷追踪与追踪系统紧密集成：

| 追踪文件 | 与跨卷追踪的关系 |
|----------|-----------------|
| 伏笔.md | 当前卷活跃伏笔，跨卷伏笔在跨卷追踪中 |
| 伏笔_索引.md | 全书伏笔索引，包含跨卷伏笔 |
| 角色状态.md | 当前卷角色状态，跨卷弧线在跨卷追踪中 |
| 角色状态_索引.md | 全书角色索引，包含弧线信息 |
| 上下文.md | 进度摘要，包含跨卷伏笔处理状态 |
