## 大纲格式规范

### 全书大纲（大纲/大纲.md）

```markdown
# {书名} 全书大纲

## 一句话梗概
{主角 + 目标 + 阻碍 + 反转}

## 卷级结构

### 第一卷：{卷名}（约 {X} 万字，{Y} 章）⏳ 进行中
- 功能：{铺垫/起步/第一个大爽点}
- 核心事件：{一句话}
- 起始状态 → 结束状态：{主角从 {A} 变成 {B}}
```

**状态标记**：⏳ 进行中 / 📝 规划中 / ✅ 已完成 / ❌ 已废弃

### 卷纲（大纲/卷纲_第X卷.md）

```markdown
# 第X卷：{卷名} 卷纲

## 卷级情绪弧线
{情绪从何处起，到何处落}

## 爽点节奏
- 第1-3章：{铺垫期}
- 第4-6章：{小爽点}

## 人物弧线
- {角色A}：{本卷成长/变化}

## 伏笔规划
- 埋设：{本卷新埋的伏笔}
- 回收：{本卷回收的伏笔}

## 反转设计
- {反转1}：{在第几章，类型}

## 弧划分（可选）
- 弧1·{弧名}（Ch{起}-{止}）：{一句话描述}

## 章节规划
- 第{N}章：{章名} — {核心事件}
```

### 细纲（大纲/细纲_第XXX章.md）

```markdown
## 细纲（第 N 章）

### 第 N 章：{章名}
- 核心事件：{一句话}
- 情节点序列：（约 200-300 字/个，下限 10 个）
- 目标情绪：{本章交付什么情绪}
- 章首钩子：{具体内容}
- 爽点：{本章爽点}
- 章尾钩子：{具体内容}
- 字数目标：{X} 字
```

## 动态扫描规范

**所有技能禁止硬编码文件清单**，必须使用以下动态扫描机制获取项目文件。

### 自动更新机制

当项目目录结构发生变化（新增文件夹/文件）时，运行以下命令更新 `project-structure.md`：

```bash
node $HOME/.config/mimocode/skills/_shared/scripts/scan-project-structure.js <项目目录>
```

此命令会扫描项目目录，输出当前文件结构。技能执行时应先运行此扫描，再基于扫描结果加载文件。

### 扫描目录清单（按场景）

技能根据自身需求，扫描对应目录获取文件列表：

| 场景 | 必须扫描的目录 | 可选扫描的目录 |
|------|---------------|---------------|
| **生成细纲** | `设定/`、`大纲/`、`追踪/` | `跨卷追踪/`、`故事线/`、`对标/` |
| **写正文** | `设定/`、`大纲/`、`追踪/` | `跨卷追踪/`、`故事线/`、`对标/`、`参考资料/` |
| **更新追踪** | `追踪/` | `设定/`、`跨卷追踪/`、`故事线/` |
| **质量检查** | `正文/`、`设定/`、`追踪/` | `跨卷追踪/`、`故事线/` |
| **进度管理** | `大纲/`、`正文/`、`追踪/` | `跨卷追踪/`、`故事线/` |
| **扫榜** | 无（项目外执行） | - |

### 扫描方法

```bash
# 方式1：运行自动扫描脚本（推荐）
node $HOME/.config/mimocode/skills/_shared/scripts/scan-project-structure.js {project_dir}

# 方式2：直接扫描特定目录
ls {project_dir}/{目录}/*.md 2>/dev/null

# 方式3：递归扫描子目录
ls {project_dir}/{目录}/**/*.md 2>/dev/null
```

### 动态加载流程

```
Step 1: 运行 scan-project-structure.js 获取项目文件结构
Step 2: 根据场景确定需要扫描的目录
Step 3: 从扫描结果中筛选需要的文件
Step 4: 按需加载 → 只读取本次需要的文件
Step 5: 缺失处理 → 按"缺失影响"列处理
```

### 缺失文件处理规则

| 文件类型 | 缺失时处理 |
|----------|-----------|
| 必需文件（设定/世界观、金手指等） | 报错阻断，提示创建 |
| 追踪文件（伏笔、时间线等） | 警告，跳过或从正文推断 |
| 跨卷追踪、故事线 | 可选，缺失不阻断 |
| 对标文件 | 可选，缺失跳过 |
