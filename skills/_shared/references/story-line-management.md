# 故事线管理

> 版本：1.0.0
> 更新时间：2026-06-12

---

## 概述

长篇小说通常包含多条故事线（主线+副线），需要独立管理和追踪。本系统提供：
- 故事线独立文件管理
- 故事线状态追踪
- 故事线交叉点标记
- 多线并行写作支持

---

## 故事线类型

| 类型 | 说明 | 特点 |
|------|------|------|
| **主线** | 推动核心剧情的主线 | 全书贯穿，章节最多 |
| **副线A** | 辅助主线的故事线 | 与主线有交叉，章节较多 |
| **副线B** | 另一条辅助故事线 | 可与主线/副线A交叉 |
| **感情线** | 角色感情发展线 | 可独立或依附主线 |
| **成长线** | 角色成长弧线 | 跨越全书，章节分散 |

## 文件结构

```
故事线/
├── 故事线_索引.md             # 所有故事线列表+状态
├── 故事线_主线_XXX.md         # 主线故事线
├── 故事线_副线A_XXX.md        # 副线A
├── 故事线_副线B_XXX.md        # 副线B
├── 故事线_感情线_XXX.md       # 感情线
├── 故事线_成长线_XXX.md       # 成长线
└── 故事线_交叉点.md           # 线与线交汇标记
```

```markdown
## 交叉点检查清单

在写交叉章节前，必须确认：

- [ ] 两条故事线的当前状态都已加载
- [ ] 交叉点的事件不会产生逻辑矛盾
- [ ] 交叉点后两条故事线的走向都已规划
- [ ] 相关角色的状态已更新
```

## 管理流程

### 1. 创建新故事线

当引入新的故事线时：

1. 在 `故事线_索引.md` 中添加新条目
2. 创建 `故事线_{类型}_{名称}.md` 文件
3. 填写基本信息和节点规划
4. 标记与其他故事线的预期交叉点

### 2. 推进故事线

每章写完后：

1. 更新当前推进的故事线节点状态
2. 检查是否到达交叉点
3. 如到达交叉点，更新 `故事线_交叉点.md`

### 3. 故事线暂停/完结

当故事线暂停或完结时：

1. 更新 `故事线_索引.md` 中的状态
2. 记录暂停/完结原因
3. 如有后续计划，记录在节点中

## 千万字级别支持

### 故事线分片

当故事线超过 100 章时，启用分片：

```
故事线/
├── 故事线_索引.md
├── 故事线_主线_XXX.md           # 当前卷活跃部分
├── 故事线_主线_XXX_归档_第1-10卷.md  # 归档部分
└── ...
```

### 并行写作支持

多条故事线可以并行推进：

1. **识别当前活跃故事线**：从索引中筛选状态为"活跃"的故事线
2. **确定本章推进哪条线**：根据细纲确定
3. **加载相关故事线状态**：读取对应的故事线文件
4. **写完后更新**：更新故事线节点和交叉点

## 与追踪系统的集成

故事线管理与追踪系统紧密集成：

| 追踪文件 | 与故事线的关系 |
|----------|---------------|
| 伏笔.md | 伏笔可能跨越多条故事线 |
| 时间线.md | 多条故事线可能有并行时间线 |
| 角色状态.md | 角色可能同时参与多条故事线 |
| 角色状态_索引.md | 快速查找角色参与的故事线 |
