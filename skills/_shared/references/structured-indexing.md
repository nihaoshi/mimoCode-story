# 结构化索引层

> 版本：1.0.0
> 更新时间：2026-06-12
> 目标：上下文加载提速3-5x

---

## 概述

千万字级项目每章需要加载14个文件，LLM上下文窗口被大量低相关信息稀释。本系统通过结构化索引层，让LLM只需读索引即可决定要加载哪些文件，而非全量扫描。

---

## 索引文件结构

```
追踪/
├── 上下文.md                    # 主上下文（含索引块）
├── 角色状态_索引.md             # 角色状态索引（每个角色一行）
├── 角色状态_详情_{角色名}.md    # 角色详情（按需加载）
├── 伏笔_索引.md                 # 伏笔索引（每个伏笔一行）
├── 伏笔_详情_{ID}.md           # 伏笔详情（按需加载）
└── 物品_索引.md                 # 物品索引（每个物品一行）
```

## 使用流程

### 日更时的索引使用

1. **Step 1：读取索引块**（<200字）
   - 从 `追踪/上下文.md` 读取索引块
   - 获取：本章涉及角色、待回收伏笔、涉及物品、环境状态

2. **Step 2：按需加载详情**
   - 根据索引块，只加载本章需要的角色详情文件
   - 根据索引块，只加载本章需要的伏笔详情文件
   - 其余文件跳过

3. **Step 3：写作**
   - 使用加载的详情进行写作

### 索引更新流程

每章写完后：

1. 更新 `追踪/上下文.md` 的索引块
2. 更新涉及角色的 `角色状态_索引.md`
3. 更新涉及伏笔的 `伏笔_索引.md`
4. 更新涉及物品的 `物品_索引.md`

## 千万字级别支持

### 分片触发条件

当以下条件满足时，自动触发分片：

| 条件 | 阈值 | 动作 |
|------|------|------|
| 活跃伏笔数 | >50条 | 创建 `伏笔_索引.md` + `伏笔_详情_*.md` |
| 活跃角色数 | >20个 | 创建 `角色状态_索引.md` + `角色状态_详情_*.md` |
| 物品数 | >30个 | 创建 `物品_索引.md` |

### 归档触发条件

| 条件 | 阈值 | 动作 |
|------|------|------|
| 已写章数 | 每50章 | 归档早期索引条目 |
| 卷结束 | 每卷结束 | 归档本卷索引，创建新卷索引 |
