# 质量规则（统一引用）

> 所有 skill 的质量约束从此文件加载，不再各自定义。修改此文件即全局生效。

---

## 一级禁用词（出现即替换）

不禁、竟然、居然、事实上、实际上、显而易见、毫无疑问、可想而知、不言而喻、与此同时、值得注意的是、需要指出的是、不可否认、嘴角勾起、嘴角上扬、嘴角微扬、眼中闪过、眼底闪过、目光中闪过、深吸一口气、长舒一口气、吐出一口浊气、缓缓开口、淡淡说道、轻声说道、仿佛、宛如、恰似、犹如、值得一提、不得不说、总而言之

## 二级禁用词（高频出现时替换）

不由得、恍若、恍如、嘴角微微上扬、眼中闪过一丝、心中暗想、一股暖流、仿佛整个世界都、视线模糊了、声音颤抖着、不禁感叹、深深地、默默地、轻轻地、缓缓地、凝视着、凝望、倒映着、诉说着、映照着

## 程度副词禁用

非常、特别、极其、十分、格外、分外、异常、相当、颇为、无比、极为

## AI 腔句式禁令

| 禁止句式 | 替换方案 |
|---------|---------|
| 他感到一股X涌上心头 | 用动作/细节代替 |
| 她的X宛如Y | 删掉比喻或换新奇比喻 |
| 这不仅X，更Y | 只说一个 |
| X的同时，Y | 分成两句 |
| 这一刻，X | 直接写X |
| 面对X，他选择了Y | 直接写他Y了 |
| 尽管X，然而Y | 直接写Y |
| 不是A，而是B | 直接写B |

## 段落规则

- 一段不超过 4 行
- 一段只承载一个动作/信息变化
- 单句超过 45 字拆短
- 段落超过 60 字按句号/动作转折拆开

## 对话规则

- 加入不完整句、打断、废话，口语化
- 不同角色说话方式要区分
- 对话标签（"他说""她道"）不超过 40%

## 心理描写规则

- 每次不超过 2 句
- 优先用动作替代（能动手别动心）

## 比喻规则

- 每千字不超过 1 个比喻
- 必须是新奇比喻（读者没见过的）

## 节奏规则

- 紧张处连续短句（3-8 字）
- 舒缓处允许长句
- 关键转折一句极短独立成段

## 留白规则

- 最强烈的感情不写
- 最重要的转折不解释
- 最美的画面不形容

## 禁止排比

- 禁止连续 3 句以上相同结构的排比
