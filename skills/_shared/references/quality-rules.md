## 一级禁用词（出现即替换）

不禁、竟然、居然、事实上、实际上、显而易见、毫无疑问、可想而知、不言而喻、与此同时、值得注意的是、需要指出的是、不可否认、嘴角勾起、嘴角上扬、嘴角微扬、眼中闪过、眼底闪过、目光中闪过、深吸一口气、长舒一口气、吐出一口浊气、缓缓开口、淡淡说道、轻声说道、仿佛、宛如、恰似、犹如、值得一提、不得不说、总而言之

## 二级禁用词（高频出现时替换）

不由得、恍若、恍如、嘴角微微上扬、眼中闪过一丝、心中暗想、一股暖流、仿佛整个世界都、视线模糊了、声音颤抖着、不禁感叹、深深地、默默地、轻轻地、缓缓地、凝视着、凝望、倒映着、诉说着、映照着

## 程度副词禁用

非常、特别、极其、十分、格外、分外、异常、相当、颇为、无比、极为

## AI 腔句式禁令

| 禁止句式 | 替换方案 |
|---------|---------|
| 他感到一股X涌上心头 | 用动作/细节代替 |
| 她的X宛如Y | 删掉比喻或换新奇比喻 |
| 这不仅X，更Y | 只说一个 |
| X的同时，Y | 分成两句 |
| 这一刻，X | 直接写X |
| 面对X，他选择了Y | 直接写他Y了 |
| 尽管X，然而Y | 直接写Y |
| 不是A，而是B | 直接写B |

## 段落规则

- 一段不超过 4 行
- 一段只承载一个动作/信息变化
- 单句超过 45 字拆短
- 段落超过 60 字按句号/动作转折拆开

## 对话规则

- 加入不完整句、打断、废话，口语化
- 不同角色说话方式要区分
- 对话标签（"他说""她道"）不超过 40%

## 心理描写规则

- 每次不超过 2 句
- 优先用动作替代（能动手别动心）

## 比喻规则

- 每千字不超过 1 个比喻
- 必须是新奇比喻（读者没见过的）

## 节奏规则

- 紧张处连续短句（3-8 字）
- 舒缓处允许长句
- 关键转折一句极短独立成段

## 留白规则

- 最强烈的感情不写
- 最重要的转折不解释
- 最美的画面不形容

## 禁止排比

- 禁止连续 3 句以上相同结构的排比

## 百分制评分规则

### 双层门禁机制

质量门禁采用双层机制：
1. **第一层：脚本检查**（客观项）— 禁用词/一致性/字数/跨章/声音/情绪/爽点
2. **第二层：LLM评分**（主观项）— 15维度百分制评分

章节必须同时通过两层才能继续：
- 第一层：无 blocker（退出码 ≠ 2）且无 warning（退出码 = 0 或 1）
- 第二层：评分 ≥ 90 分

### 退出码说明

| 退出码 | 含义 | 触发条件 |
|--------|------|----------|
| 0 | pass | 全部检查通过，评分 ≥ 90 |
| 1 | warn | 有警告但无阻断，评分 ≥ 90 |
| 2 | blocked | 有阻断项（必须修复） |
| 3 | score_fail | 规则检查通过但评分 < 90 |

### 15 个评分维度

| 维度 | 满分 | 评判重点 |
|------|------|---------|
| 开场吸引力 | 8 | 悬念钩子、冲突引入、亲和力开场 |
| 情感深度 | 8 | 内心变化、共鸣代入、情感层次 |
| 叙述结构 | 8 | 层次递进、结构紧凑、逻辑清晰 |
| 语言生动性 | 7 | 视觉语言、通俗易懂、多样化叙述 |
| 细节描写 | 7 | 画面感、具体生动、悬念保持 |
| 过渡连贯 | 6 | 自然过渡、节奏紧凑、思考空间 |
| 逻辑清晰 | 7 | 观点有力、深入剖析、立场鲜明 |
| 对比反差 | 6 | 主题突出、情感冲突、冲击力 |
| 情感张力 | 7 | 张力吸引、高潮引导、冲击力 |
| 人性化亲和 | 6 | 贴近生活、引发共鸣、故事性 |
| 视觉感官 | 7 | 视觉化、多感官、沉浸感 |
| 节奏流畅 | 7 | 紧凑不拖、节奏感、速度控制 |
| 逻辑连贯 | 6 | 情节连贯、时间线清晰、因果合理 |
| 细节具体化 | 5 | 具体例子、推动情节、悬念揭示 |
| 情感爆发力 | 5 | 积累自然、爆发有力、记忆点 |

### 题材模板

15 套题材模板位于 `score-templates/` 目录，通过 `--genre` 参数选择：
- default（默认/通用）、xuanhuan（玄幻）、xianxia（仙侠）、dushi（都市）
- xuanyi（悬疑）、yanqing（言情）、lishi（历史）、kehuan（科幻）
- moshi（末世）、chongsheng（重生）、chuanyue（穿越）、xitong（系统流）
- wuxianliu（无限流）、gongdou（宫斗/宅斗）、duanpian（短篇）

每套模板调整各维度权重分配，以适应不同题材的侧重需求。

### 评分不达标处理

1. 定位低分维度（score < 满分60%的维度）
2. 针对低分维度生成修复指令
3. 子 agent 执行定向修复（仅改低分维度涉及的内容）
4. 修复后重新评分
5. 最多 3 轮修复
6. 3 轮后仍 < 90 → 阻断，输出最终评分报告
