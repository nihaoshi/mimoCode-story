# 追踪文件更新规则（统一引用）

> 所有 skill 的追踪文件更新规则从此文件加载，不再各自定义。

---

## 写完每章必须更新的文件

| 序号 | 文件 | 更新内容 | 更新时机 |
|------|------|---------|---------|
| 1 | `追踪/伏笔.md` | 新增/回收伏笔，更新紧迫度 | 每章写完后 |
| 2 | `追踪/时间线.md` | 记录事件时序，更新季节/时间 | 每章写完后 |
| 3 | `追踪/角色状态.md` | 更新角色身份、能力、关系、性格锚点 | 每章写完后 |
| 4 | `追踪/物品.md` | 更新物品位置、状态变化 | 每章写完后 |
| 5 | `追踪/环境.md` | 更新季节、天气、场景位置 | 每章写完后 |
| 6 | `追踪/物资.md` | 更新钱财、食物、工具状态 | 每章写完后 |
| 7 | `追踪/重复语句.md` | 记录重复表达黑名单 | 每章写完后 |
| 8 | `追踪/上下文.md` | 更新进度摘要 | 每章写完后 |
| 9 | `故事线/故事线_索引.md` | 更新故事线状态 | 每章写完后 |
| 10 | `故事线/故事线_主线_*.md` | 更新主线/副线进展 | 每章写完后 |
| 11 | `故事线/故事线_交叉点.md` | 更新交叉点标记 | 每章写完后 |

**更新顺序**：必须串行执行，不能并行。

---

## 角色同步检查

更新角色状态后，运行：
```bash
node $HOME/.config/mimocode/skills/_shared/scripts/character-sync.js <项目目录> --json
```

验证 `设定/角色/` 和 `追踪/角色状态.md` 一致。

## 追踪文件缺失处理

| 文件 | 缺失严重度 | 处理方式 |
|------|-----------|---------|
| `追踪/伏笔.md` | WARN | 列出缺失，问用户是否创建 |
| `追踪/时间线.md` | WARN | 列出缺失，问用户是否创建 |
| `追踪/角色状态.md` | WARN | 从角色设定推断，问用户是否创建 |
| `追踪/物品.md` | WARN | 列出缺失，问用户是否创建 |
| `追踪/环境.md` | WARN | 列出缺失，问用户是否创建 |
| `追踪/物资.md` | WARN | 列出缺失，问用户是否创建 |
| `追踪/上下文.md` | WARN | 自动创建 |
| `故事线/` 目录 | INFO | 缺失则跳过，不阻塞 |
| `跨卷追踪/` 目录 | INFO | 缺失则跳过，不阻塞 |

---

## 追踪文件归档

每完成 50 章或一个卷结束时：
- 对 `追踪/上下文.md` 做轻量归档
- 保留最近 5 章详记
- 将更早内容压缩到 `追踪/归档/第XXX-YYY章.md`
- 伏笔、时间线、角色状态以当前文件为准，不移入归档

---

## 引用方式

在 SKILL.md 中引用此文件：
```
追踪更新规则详见 `_shared/references/tracking-update-rules.md`。
```
