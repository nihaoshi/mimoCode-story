## 核心理念

**AI的文字：什么都说了，但什么都没留下。**
**人类的文字：什么都没说透，但什么都留在了心里。**

去AI味的本质：从"说清楚"变成"让人感受到"。

---

## 一、AI味的六大特征

| 特征 | 说明 | AI典型输出 | 人类写法 |
|------|------|-----------|---------|
| ① 万能副词滥用 | 每段都有程度副词修饰 | "他非常愤怒地瞪着她" | "他瞪着她" |
| ② 心理直白宣泄 | 把内心感受直接写出来 | "他感到一股暖流涌上心头" | "他别过脸，喉结动了一下" |
| ③ 比喻泛滥 | 动不动就像什么一样 | "她的笑容宛如春风拂过湖面" | "她笑了" |
| ④ 结构对称强迫 | 每段都是"不仅…而且…""既…又…" | "他既感到愤怒，又感到无奈" | "他攥紧了拳头，半天没说话" |
| ⑤ 和谐大团圆语气 | 永远温和、周全、不得罪 | "这让我们深思…" | 不下结论，留白 |
| ⑥ 高频套话词表 | 固定搭配反复出现 | "不禁""宛如""嘴角微微上扬" | 不用这些词 |

**根本原因**：AI的训练目标是最小化"让大多数人觉得不自然"的概率——所以它选择的是最安全的写法。而好的文学写作恰恰是不安全的——它敢留白、敢突兀、敢不解释、敢用不完美的句子。

## 二、去AI味前置约束（写作时必须遵守）

> ⚠️ 以下规则在写作时就必须遵循，不是写完再改。

### 2.1 禁止词汇（出现即删）

```
不由得、不禁、宛如、恍若、犹如、恍如、似是而非、仿佛、
嘴角微微上扬、眼中闪过一丝、心中暗想、一股暖流、
仿佛整个世界都、视线模糊了、声音颤抖着、不禁感叹、
深深地、默默地、轻轻地、缓缓地、凝视着、凝望、
倒映着、诉说着、映照着、如X般、似X一般
```

### 2.2 禁止句式（出现即改）

| 禁止句式 | 改法 |
|----------|------|
| "他感到一股X涌上心头" | 用动作/细节代替 |
| "她的X宛如Y" | 删掉比喻或换新奇比喻 |
| "这不仅X，更Y" | 只说一个 |
| "X的同时，Y" | 分成两句 |
| "这一刻，X" | 直接写X |
| "面对X，他选择了Y" | 直接写他Y了 |
| "尽管X，然而Y" | 直接写Y |
| "不是A，而是B" | 直接写B |
| "，带着……" | 拆短句或换动作 |
| "声音不大，却带着……" | 直接写声音特征或动作 |
| "他/她知道……" | 用行为展示认知 |

### 2.3 程度副词禁用

**全部删掉**：非常、特别、极其、十分、格外、分外、异常、相当、颇为、无比、极为

### 2.4 比喻规则

- **每千字不超过1个比喻**
- 必须是**新奇的比喻**（读者没见过的）
- 好比喻特征：两个事物之间有不寻常的相似点，读者读到会愣一下然后拍大腿
- 日常但精准——"他笑得像偷了鸡"比"他笑得如沐春风"好100倍

### 2.5 心理描写规则

- **每次不超过2句**
- **优先用动作替代**
- 口诀：**能动手别动心**

| 心理直白 | 动作替代 |
|----------|----------|
| 他感到非常愤怒 | 他一拳砸在桌上 |
| 她心里很难过 | 她低头搅杯子，半天没喝 |
| 他觉得很温暖 | 他把围巾往上拽了拽 |
| 她感到无比失落 | 她把手机翻过去扣在桌上 |

### 2.6 段落规则

- **一段不超过4行**
- **一段只承载一个动作/信息变化**
- **单句超过45字拆短**
- **长短句交错**，不能全是一种节奏

### 2.7 节奏规则

| 场景 | 节奏 |
|------|------|
| 紧张处 | 连续短句，每句3-8字 |
| 舒缓处 | 允许长句铺开 |
| 关键转折 | 一句极短，独立成段 |
| 对话后 | 加一个动作句打断节奏 |

### 2.8 对话规则

- 加入**不完整句、打断、废话**
- 口语化，不要书面语
- 不同角色说话方式要区分

| 毛刺类型 | 说明 | 示例 |
|----------|------|------|
| 不完整句 | 说话说到一半 | "我当时就想——算了不说了" |
| 口头禅 | 角色独特的习惯用语 | "我说真的""你别急嘛""不是吧" |
| 废话感 | 真人说话的废话 | "那个……就是……嗯，行吧" |
| 打断 | 说话被打断 | "你听我说——""我不要听！" |
| 自相矛盾 | 人说话本就矛盾 | "我没生气，就是——好吧我生气了" |

### 2.9 留白规则

- **最强烈的感情不写**——写周围的反应
- **最重要的转折不解释**——读者自己会懂
- **最美的画面不形容**——一个动作就够了

| AI要说透 | 人类留白 |
|----------|----------|
| 他终于释然了，放下了多年的执念 | 他把那封信折好，放进抽屉。再没提过 |
| 她深深地爱着他，这份爱超越了时间 | 她给他留了一盏灯。每晚 |
| 这个结局令人唏嘘不已 | 他站在那里，很久。风把门吹开了，他没去关 |

### 2.10 禁止排比

- **禁止连续3句以上相同结构的排比**
- **禁止"有的...有的...有的..."句式**
- **禁止"一边...一边...一边..."句式**

| AI排比 | 人类写法 |
|--------|----------|
| 他看着她的眼睛，看着她的嘴唇，看着她微微颤动的睫毛 | 他看着她。她没说话。 |
| 她喜欢春天的花朵，喜欢夏天的阳光，喜欢秋天的落叶，喜欢冬天的白雪 | 她喜欢春天。别的季节也还行。 |

## 三、去AI味七步法（写作后检查）

> 写完每章后，按以下步骤检查和修改。

### 第一步：删副词

把所有程度副词划掉，看句子的骨架还在不在。在=副词是废话，删。

| 原句 | 删副词后 |
|------|----------|
| 他非常愤怒地摔门而去 | 他摔门而去 |
| 她极其温柔地笑了笑 | 她笑了笑 |
| 那个消息让他十分震惊 | 那个消息让他愣住了 |
| 空气仿佛凝固了一般 | 空气凝固了 |

### 第二步：砍心理

把所有"他感到""他心里""他觉得"开头的句子划掉，换成动作。

| 心理直白 | 动作替代 |
|----------|----------|
| 他感到非常愤怒 | 他一拳砸在桌上 |
| 她心里很难过 | 她低头搅杯子，半天没喝 |
| 他觉得很温暖 | 他把围巾往上拽了拽 |
| 她感到无比失落 | 她把手机翻过去扣在桌上 |

### 第三步：砍比喻

AI的比喻99%是废话比喻——删掉不影响理解，换掉才增色。

| 废话比喻 | 删掉/替换 |
|----------|-----------|
| 她的眼泪宛如断了线的珠子 | 她哭了（或：眼泪掉下来，砸在手背上） |
| 他的声音像是从深渊传来 | 他声音哑了 |
| 夕阳如血般染红了天际 | 夕阳把天烧红了 |
| 她的笑容像春天的花朵 | 她笑了 |

### 第四步：破对称

AI爱写对仗句、并列句、"不仅而且"句。打破它们。

| 对称句 | 破对称 |
|--------|--------|
| 他既愤怒又悲伤 | 他攥紧了拳头 |
| 这不仅是勇气的考验，更是智慧的挑战 | 这是赌命 |
| 她既想靠近又害怕受伤 | 她往前走了半步，又停了 |

### 第五步：加毛刺

AI的文字太光滑了，没有生活的毛刺。加入以下元素增加粗糙感：

| 毛刺类型 | 说明 | 示例 |
|----------|------|------|
| 不完整句 | 说话说到一半 | "我当时就想——算了不说了" |
| 口头禅 | 角色独特的习惯用语 | "我说真的""你别急嘛""不是吧" |
| 废话/废话感 | 真人说话的废话 | "那个……就是……嗯，行吧" |
| 打断 | 说话被打断 | "你听我说——""我不要听！" |
| 自相矛盾 | 人说话本就矛盾 | "我没生气，就是——好吧我生气了" |
| 不优雅的动作 | 真实但不美的动作 | 挖鼻孔、抠指甲、弹灰、抖腿 |

### 第六步：调节奏

AI的段落长度和句子长度太均匀了。真人写作是参差的：

- **紧张处**：连续短句，每句3-8字
- **舒缓处**：允许长句铺开
- **关键转折**：一句极短，独立成段
- **对话后**：加一个动作句打断节奏

### 第七步：加留白

AI最不会留白——它总想解释清楚。但好文字是不说透的。

**留白三原则**：
1. 最强烈的感情不写——写周围的反应
2. 最重要的转折不解释——读者自己会懂
3. 最美的画面不形容——一个动作就够了

## 四、系统性去AI味三遍法

### Pass 1：去泛化（Strip Generic）

- 抽象情绪总结句 → 删或替换为具体动作
- 假深度句 → 删
- 意义膨胀 → 缩小到具体影响
- 空洞结论 → 删
- 工整对比句式 → 打散重写
- 装饰性形容词堆砌 → 白描
- 过度使用"于是""然而""此刻" → 删掉一半
- 所有角色说话一样"高级" → 区分语气

**原则**：能删就删，不能删就用具体细节替换。这一遍去掉80%的AI味。

### Pass 2：去书面化（Cut Professional Diction）

- 分析性用词（"机制""结构""逻辑""体系"出现在小说中）→ 换成日常表达
- 抽象名词滥用 → 直接说事
- 体制内用语（"进一步""深入""推进""落实"）→ 删
- 专业术语堆砌 → 只保留必要的，用白话解释

**例外**：保留专业感的场景（历史题材正式用语、文学向刻意密度、喜剧夸张修辞）。

### Pass 3：回自然感（Restore Natural Presence）

- 具体的感官细节（气味、温度、触感）
- 角色说话方式的区分（不同人不同语气）
- 节奏变化（长短句交错）
- 社会位置感的对话（上级和下属说话方式不同）
- 场景特有的记忆点
- 项目特有的语言习惯（角色的口头禅）

**原则**：少即是多。每段加1-2个具体细节就够了。

### 升级策略

| AI味程度 | 策略 |
|----------|------|
| 轻度 | 只做Pass 1 |
| 中度 | Pass 1 + Pass 2 |
| 重度 | 完整三遍 + 重点段落重写 |

## 五、7种AI写作模式检测

### 模式1：AI高频词

| 禁用 | 替换为 |
|------|--------|
| 不禁 | 删掉 |
| 仿佛/宛如 | 删掉或用具体描写 |
| 映入眼帘 | 删掉 |
| 心中暗道 | 用动作展示思考 |
| 沉声道/淡淡地说 | 换成动作标签 |
| 脸色一变 | 用具体表情/动作 |
| 嘴角微扬 | 他笑了/他翘了下嘴 |
| 不由自主 | 删掉 |
| 只见/此时此刻 | 删掉 |
| 目光如炬 | 删掉或具体化 |

### 模式2：弱化副词泛滥

阈值：每1000字超过3个 = AI签名。重点监控：微微、淡淡、缓缓、轻轻。

### 模式3：意义膨胀

- "意义深远" → 写具体后果
- "前所未有" → 给出对比参照
- "可谓" → 删掉

### 模式4：万能结论

- "未来可期" → 用未解决的紧张感结尾
- "前途无量" → 删
- "充满希望" → 写具体的下一步动作

### 模式5：论文体段落结构

小说中出现以下开头句 = AI入侵：
- "不难看出""由此可见""事实上""综上所述"

### 模式6：书面语连词泛滥

叙事散文中频繁出现："于是乎""与此同时""从而""因而""诚然" → 口语化替代或直接删除。

### 模式7：三连排比癖

AI喜欢把事情凑成三个以显"完整"。→ 砍到只剩最有力的一条。

## 六、AI高频套话完整词表

### 6.1 必删词（替换为空或改写）

| AI味词汇 | 出现频率 | 为什么AI爱用 | 怎么改 |
|----------|----------|-------------|--------|
| 不由得 | ★★★★★ | AI的"安全过渡词" | 直接删掉 |
| 不禁 | ★★★★★ | 同上 | 直接删掉 |
| 宛如 | ★★★★ | AI最爱比喻词 | 换成"像"或删掉比喻 |
| 恍若 | ★★★★ | 宛如的变体 | 同上 |
| 犹如 | ★★★★ | 宛如的变体 | 换成"像"或删 |
| 恍如 | ★★★ | 宛如的变体 | 同上 |
| 仿佛 | ★★★★ | AI比喻标配 | 换成"像"或删 |
| 倒映着 | ★★★ | AI写眼神必用 | 换具体描写 |
| 诉说着 | ★★★ | AI写物必用 | 删 |
| 映照着 | ★★★ | 同上 | 删 |
| 凝视着 | ★★★★ | AI写看必用 | 换成"看着""盯着" |
| 凝望 | ★★★ | 同上 | 同上 |

### 6.2 必改词（替换为更自然的表达）

| AI味表达 | 改为 | 示例 |
|----------|------|------|
| 嘴角微微上扬 | 笑了笑/咧嘴/嘴角动了动 | "她嘴角微微上扬"→"她笑了" |
| 眼中闪过一丝X | 眼神变了/目光一沉/眼里有了X | "眼中闪过一丝悲伤"→"眼神暗了一下" |
| 心中暗想 | （直接删） | "他心中暗想：不好"→"不好。" |
| 一股暖流涌上心头 | （用动作代替） | →"他鼻子一酸" |
| 仿佛整个世界都X | （删掉夸张） | →具体写眼前的东西 |
| 视线模糊了 | 眼眶热了/眼睛酸了 | "视线模糊了"→"眼眶一热" |
| 声音颤抖着说 | （用动作打断） | →"他张了张嘴，没出声" |
| 不禁感叹 | （删） | →直接写感慨的话 |
| 深深地X了X | X了X | "深深地叹了口气"→"叹了口气" |
| 默默地X | X | "默默地走开"→"走开了" |
| 轻轻地X | X/换了动词 | "轻轻地关门"→"带上门" |
| 缓缓地X | X/换了动词 | "缓缓地开口"→"开口" |

### 6.3 必改句式

| AI句式 | 人类写法 | 改法 |
|--------|----------|------|
| "他感到一阵X涌上心头" | 用动作/细节代替 | 删掉感受句，加动作句 |
| "她的X仿佛/宛如Y" | 要么不用比喻，要么用出其不意的比喻 | 删比喻或换新奇比喻 |
| "这不仅X，更Y" | 只说一个 | 删掉"不仅"那半句 |
| "X的同时，Y" | 分成两句 | 断开 |
| "这一刻，X" | 直接写X | 删"这一刻" |
| "他知道X，但Y" | 直接写Y | 删"他知道X" |
| "尽管X，然而Y" | 直接写Y | 删"尽管"句 |
| "面对X，他选择了Y" | 直接写他Y了 | 删铺垫 |

## 七、Show Don't Tell 原则

| Tell（告诉） | Show（展示） |
|-------------|-------------|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上，卡面上的数字比这顿饭贵十倍 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里，她面无表情地把杯子推到一边 |
| 他很聪明 | 三秒钟。他看了三秒钟就把文件合上了。"第三页，第二行。" |

**核心方法**：
1. 用行为代替形容词
2. 用细节代替总结
3. 用对话代替旁白说明
4. 用反应代替情绪词

## 八、改写范例库

### 情绪外化范例

| 情绪 | AI写法 | 自然写法 |
|------|--------|----------|
| 紧张 | "他感到一阵紧张，心跳不由自主地加快了" | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒 | "愤怒在他心中燃烧，他不由得握紧了拳头" | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 悲伤 | "一丝悲伤涌上心头，她的眼中闪过泪光" | 她低头搅着咖啡，搅了很久 |
| 害怕 | "恐惧瞬间笼罩了他，他感到一阵战栗" | 他的背贴在墙上，不敢动 |
| 失望 | "她感到一丝失落，心仿佛被什么东西揪住了" | "哦。"她把手机锁了屏 |
| 惊讶 | "他的瞳孔微微收缩，显然没有想到会听到这样的话" | 他张了张嘴，什么都没说出来 |

### 场景描写范例

**AI风场景**：
> 阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影。空气中弥漫着淡淡的花香，仿佛整个世界都沉浸在一片宁静祥和的氛围中。

**人类写法**：
> 下午三点，客厅里只有钟在走。

**AI风天气**：
> 天空阴沉沉的，乌云密布，仿佛随时都会下起倾盆大雨。凛冽的寒风呼啸而过，带着一丝刺骨的寒意。

**人类写法**：
> 要下雨了。风把晾在外面的衣服吹得乱晃。

**AI风打斗**：
> 他的拳头犹如疾风骤雨般猛烈，每一击都蕴含着不容置疑的力量。对手的瞳孔微微收缩，显然没有预料到如此凌厉的攻势。

**人类写法**：
> 他一拳怼过去，对方没躲开，嘴角破了。

### 结尾改写范例

| AI结尾 | 人类结尾 |
|--------|----------|
| "他站在窗前，望着远方的天际线，终于明白了生活的真谛：有时候，放手才是最好的选择。" | 他把烟掐了，回屋睡觉。 |
| "这一刻，一切都变了。她知道，从今以后，她的人生将翻开崭新的一页。" | 她关上了那扇门。没回头。 |
| "岁月如流水般悄然流逝……" | 直接删掉这种段落。 |

## 九、AI特殊标点清理

> AI生成文本除了普通标点，还经常使用印刷级标点（智能引号/破折号），有时会夹带不可见Unicode字符。

### 9.1 AI偏爱的印刷级可见标点

> **重要区分**：`——`（全角破折号）和 `……`（全角省略号）是正常中文标点，可用于中文正文。
> 仅检测西文排版标点（en dash、智能引号、不换行空格等）。

| 类型 | AI常用（Unicode） | 普通键盘输入 | 说明 |
|------|------------------|-------------|------|
| en dash | –（U+2013） | - | 数字区间 |
| 智能引号 | "（U+201C）"（U+201D）、'（U+2018）'（U+2019） | "' | 弯引号/印刷引号，非直引号 |
| 不换行空格 | NBSP（U+00A0）、窄不换行空格（U+202F） | 普通空格 | 数字与单位间常出现 |
| 特殊连字符 | ‑（U+2011 不换行连字）、‐（U+2010 连字符） | - | 偶尔出现在排版严谨内容中 |

**中文标点使用规则**：
- `——`（全角破折号）：中文正文应避免使用，替换为逗号或句号。数字区间（如 2020——2025）例外
- `……`（全角省略号）：正常中文标点，可使用，但密度不宜过高（>5次/百字需精简）
- 中文使用全角标点，英文使用半角标点

### 9.2 不可见/特殊Unicode字符（AI指纹）

| 类型 | Unicode | 说明 |
|------|---------|------|
| 零宽空格 | U+200B | 肉眼不可见 |
| 零宽非连接符 | U+200C | 肉眼不可见 |
| 零宽连接符 | U+200D | 肉眼不可见 |
| 不换行空格 | U+00A0 | 数字与单位间常出现 |
| 窄不换行空格 | U+202F | 数字与单位间常出现 |
| 细空格 | U+2009 | 肉眼不可见 |
| 全角空格 | U+3000 | 中文排版用 |
| BOM/控制符 | U+FEFF | 字节序标记 |
| 软连字符 | U+00AD | 肉眼不可见 |

### 9.3 清理规则

**写作时**：
- 使用普通键盘标点，不用智能引号和 en dash
- 中文使用全角标点，英文使用半角标点
- 中文正文不使用破折号（`——`），用逗号或句号替代
- 不使用零宽字符和特殊空格

**写完后**：
- 运行 `node scripts/normalize-punctuation.js` 自动清理
- 检查并替换智能引号为直引号
- 清理不可见Unicode字符
- 归一化空格（NBSP→普通空格）

## 十、跨章重复检测

> AI写作容易产生跨章节的重复内容，需要在写作时和写完后双重检测。

### 10.1 常见跨章重复类型

| 重复类型 | 说明 | 示例 |
|----------|------|------|
| 句子级重复 | 相同句子在多章出现 | "他攥紧了拳头" 在第3/4/5章都出现 |
| 段落级重复 | 相似段落结构在多章出现 | 每章开头都是"阳光透过窗帘" |
| 动作重复 | 相同动作描写反复使用 | "深吸一口气" 每章都用 |
| 场景重复 | 相似场景描述反复出现 | 每次紧张都是"心跳加速" |

### 10.2 写作时预防

**读取前 5 章指纹**：在 Phase 4 Step 2 读取 `追踪/cross-chapter-fingerprint.md`，了解前 5 章的高频重复内容。

**避免重复**：写作时主动避免以下内容：
- 前 5 章出现 2 次以上的句子片段
- 前 5 章出现 3 次以上的动作描写
- 前 5 章出现 2 次以上的场景描述

### 10.3 写完后检测

**自动检测**：运行 `node $HOME/.config/mimocode/skills/_shared/scripts/cross-chapter-check.js` 自动检测跨章重复。

**检测范围**：当前章 + 前 5 章（滑动窗口）

**检测项**：
1. 句子级重复：6 字以上子串在其他章节出现 ≥2 次
2. 段落级重复：连续 2+ 句子结构相同
3. 高频动作重复：相同动作描写在近 5 章重复 ≥3 次

### 10.4 修复方法

| 重复类型 | 修复方法 |
|----------|----------|
| 句子重复 | 换一种表达方式，或删除冗余句子 |
| 段落重复 | 改变段落结构，加入新细节 |
| 动作重复 | 用不同动作替代，或加入个性化细节 |
| 场景重复 | 改变场景描写角度，加入感官细节 |

## 十二、终极检验法

### 12.1 朗读法

把你的文字大声读出来。
- 读着拗口 → 句子结构有问题
- 读着平淡 → 缺动作细节
- 读着矫情 → 比喻和心理太多
- 读着顺畅但没感觉 → 缺留白和毛刺

### 12.2 遮名法

把角色名字遮住，看能不能分辨谁在说话。
- 能分辨 → 对话有性格，好
- 不能分辨 → 对话是AI写的，需要改

### 12.3 副词清点法

数一数每千字有多少个程度副词和AI套话词。

| 每千字数量 | 评价 |
|------------|------|
| 0-2个 | ✅ 基本无AI味 |
| 3-5个 | ⚠️ 有轻微AI味 |
| 6-10个 | ❌ AI味明显 |
| 10个以上 | ❌❌ 典型AI文 |

### 12.4 冷读法

放24小时再看。如果产生"这真的是我写的吗"的陌生感中的尴尬感——说明AI味还在。如果陌生感中是惊喜感——说明去味成功了。

## 十二、质量检查清单

写完每章后，按此清单逐项扫描：

### 前置检查（写作时）

- [ ] **无禁止词汇**：无不由得/不禁/宛如/仿佛/嘴角微微上扬等
- [ ] **无禁止句式**：无"他感到一股X涌上心头"/"这不仅X，更Y"等
- [ ] **无程度副词**：无非常/特别/极其/十分等
- [ ] **比喻≤1个/千字**：且必须是新奇比喻
- [ ] **心理描写≤2句**：且用动作替代
- [ ] **段落≤4行**：一段只承载一个动作/信息变化
- [ ] **无排比句式**：无连续3句以上相同结构

### 后置检查（写完后）

- [ ] **段落控制**：段落按动作/信息变化断开，读起来不卡
- [ ] **AI高频词扫描**：无不禁/仿佛/映入眼帘/心中暗道/沉声道/嘴角微扬/不由自主/只见
- [ ] **弱化副词计数**：每1000字"微微/淡淡/缓缓/轻轻"不超过3个
- [ ] **无三连排比**：没有AI式的"三个一组"修辞
- [ ] **无论文体**：无"不难看出/由此可见/事实上/综上所述"
- [ ] **无书面语连词堆砌**：无"于是乎/与此同时/从而/因而/诚然"泛滥
- [ ] **章尾无总结升华**：用动作/对话/悬念收束，无感悟/哲理/预告
- [ ] **无大段心理描写**：心理活动不超过2段，无括号标注内心
- [ ] **情绪用动作展示**：无直接写"愤怒/伤心/紧张"，全用身体反应
- [ ] **对话口语化**：无书面腔，不同角色语气可区分
- [ ] **Show Don't Tell**：用行为代替形容词，用细节代替总结
- [ ] **句长匹配场景**：打斗和冲突段更短，日常和描写段可稍长
- [ ] **去AI三遍法执行**：轻度只做Pass1，中度做Pass1+2，重度完整三遍

## 十三、风格参考法（最有效的去AI味方法）

给AI一段你想要的风格的参考文字，让它模仿：

```
请用以下参考文字的风格来写，保持相同的语言质感：

【参考风格】
"那天下午他没去上班。坐在阳台上抽了半包烟，看楼下的人走来走去。
手机响了两次，他没接。第三次是妈打来的，他接了，说在公司忙。
挂了电话又点了根烟。楼下的快递员在喊谁的名字，喊了三遍没人应。"

【写作任务】
（你的写作任务）
```

为什么有效：AI看到具体的风格样本后，会模仿那个节奏、那个密度、那个口语化程度——这比任何抽象规则都有效。
