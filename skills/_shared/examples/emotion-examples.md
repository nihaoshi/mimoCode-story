# 情感线案例库

> 从经典作品中提取的情感线设计技巧。

---

## 案例 1：慢热型情感线

**来源**：经典言情

**结构**：
```
相识（陌生）→ 相知（了解）→ 好感（心动）→ 误会（分离）→ 和好（确认）
```

**关键节点**：
1. **初见**：第一印象要具体（不要"他很帅"）
2. **了解**：通过事件展示性格
3. **心动**：用细节表达（心跳加速、脸红、手心出汗）
4. **误会**：合理的误会（不是故意制造矛盾）
5. **和好**：坦诚沟通 + 成长

**可借鉴**：
- 慢热的节奏控制
- 用细节表达情感
- 误会要合理

## 案例 2：虐心型情感线

**来源**：虐恋小说

**结构**：
```
相遇（美好）→ 相恋（甜蜜）→ 背叛（痛苦）→ 分离（绝望）→ 重逢（复杂）
```

**关键节点**：
1. **美好**：建立美好的回忆
2. **甜蜜**：让读者投入感情
3. **背叛**：制造巨大的情感落差
4. **痛苦**：展示真实的痛苦
5. **重逢**：复杂的情感（爱恨交织）

**可借鉴**：
- 先甜后虐的节奏
- 情感落差的控制
- 重逢的复杂情感

## 案例 3：暗恋型情感线

**来源**：青春小说

**结构**：
```
暗恋（默默关注）→ 接近（找借口）→ 试探（旁敲侧击）→ 表白/放弃
```

**关键节点**：
1. **暗恋**：用细节展示关注（记住对方的习惯、喜好）
2. **接近**：找各种借口接近
3. **试探**：旁敲侧击，试探心意
4. **表白/放弃**：最终的选择

**可借鉴**：
- 暗恋的细节描写
- 试探的技巧
- 表白/放弃的时机

## 案例 4：破镜重圆型情感线

**来源**：都市小说

**结构**：
```
相爱（甜蜜）→ 分离（原因）→ 重逢（尴尬）→ 了解真相 → 和好
```

**关键节点**：
1. **相爱**：建立曾经的美好
2. **分离**：合理的分离原因
3. **重逢**：尴尬 + 复杂情感
4. **真相**：当年的误会/苦衷
5. **和好**：理解 + 宽容 + 成长

**可借鉴**：
- 分离原因的合理性
- 重逢的尴尬感
- 真相的冲击力

## 案例 5：禁忌型情感线

**来源**：古装小说

**结构**：
```
相遇（身份限制）→ 心动（克制）→ 试探（危险）→ 决定（选择）
```

**关键节点**：
1. **身份限制**：明确的障碍（君臣、师徒、敌对）
2. **心动**：克制的情感（不能表达）
3. **试探**：危险的试探（可能暴露）
4. **决定**：最终的选择（放弃/冒险）

**可借鉴**：
- 禁忌感的营造
- 克制的情感表达
- 选择的重量感
