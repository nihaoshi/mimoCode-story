# 对话案例库

> 从经典作品中提取的对话技巧案例。

---

## 案例 1：潜台词对话

**来源**：经典小说对话

**场景**：两人吵架，但都不直说

**原文示例**：
```
"你今天回来得真早。"
"嗯。"
"饭做好了。"
"不饿。"
"那我去倒了。"
"随便。"
```

**分析**：
- 表面：日常对话
- 潜台词：冷战、不满、等待对方先低头
- 技巧：用短句制造距离感，用"随便"表达情绪

**可借鉴**：
- 冷战时的对话特点
- 用动作代替心理描写
- 留白让读者自己体会

---

## 案例 2：信息差对话

**来源**：悬疑小说

**场景**：主角知道真相，但对方不知道

**原文示例**：
```
"你知道他为什么离开吗？"
"不知道。"
"他去了北方。"
"哦。"
"那边很冷。"
"嗯。"
"他带走了所有衣服。"
"......"
```

**分析**：
- 信息差：读者和主角知道真相，对方不知道
- 技巧：用平淡的对话传递重要信息
- 效果：制造悬念，让读者着急

**可借鉴**：
- 信息差的运用
- 平淡对话中的张力
- 让读者比角色更着急

## 案例 3：潜台词表白

**来源**：言情小说

**场景**：表白，但不直说

**原文示例**：
```
"你以后有什么打算？"
"不知道。"
"留在这里？"
"可能吧。"
"那挺好的。"
"你呢？"
"我？"
"你以后想去哪？"
"......没想好。"
"那我们一起想？"
"好。"
```

**分析**：
- 表面：讨论未来
- 潜台词：想和你在一起
- 技巧：用"一起"暗示关系

**可借鉴**：
- 表白可以不直说
- 用"我们"暗示关系
- 留白让读者心动

## 案例 4：争吵升级

**来源**：家庭剧

**场景**：夫妻吵架

**原文示例**：
```
"你又回来这么晚。"
"加班。"
"天天加班。"
"没办法。"
"你就不能早点？"
"我说了没办法！"
"你就知道工作！"
"我不工作谁养你？"
"我自己能养自己！"
"那你说啊！"
"我说什么？"
"你说啊！"
"......"
```

**分析**：
- 节奏：短句制造紧张
- 升级：从抱怨到指责到攻击
- 转折：沉默比争吵更有力

**可借鉴**：
- 争吵的节奏控制
- 情绪升级的层次
- 沉默的力量

---

## 案例 5：告别对话

**来源**：战争小说

**场景**：送别

**原文示例**：
```
"路上小心。"
"嗯。"
"到了写信。"
"好。"
"别忘了。"
"不会。"
"......"
"我走了。"
"嗯。"
```

**分析**：
- 极简：每句都很短
- 情感：用沉默表达不舍
- 技巧：越简单越有重量

**可借鉴**：
- 告别时的极简对话
- 用沉默表达情感
- 简单就是力量
