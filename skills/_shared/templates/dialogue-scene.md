# 对话场景模板

> 使用方法：根据场景选择模板，填充具体内容。

---

## 模板 1：冲突对话

```
【场景设定】
- 地点：
- 时间：
- 氛围：

【对话结构】
1. 开场（1-2句）：建立场景，引入话题
2. 冲突（3-5句）：观点对立，情绪升级
3. 转折（1-2句）：新信息/反转
4. 收尾（1-2句）：情绪落点

【注意事项】
- 每句对话后加动作/表情
- 潜台词 > 直说
- 节奏：短句制造紧张，长句缓冲
```

---

## 模板 2：情感对话

```
【场景设定】
- 人物关系：
- 当前状态：
- 情感目标：

【对话结构】
1. 铺垫（2-3句）：日常话题，隐藏情感
2. 试探（2-3句）：旁敲侧击，试探心意
3. 表白/拒绝（1-2句）：核心情感表达
4. 余韵（1-2句）：情绪延续

【注意事项】
- 用动作代替心理描写
- 留白 > 说破
- 环境描写烘托情绪
```

---

## 模板 3：信息传递对话

```
【场景设定】
- 传递什么信息：
- 为什么用对话传递：
- 接收者反应：

【对话结构】
1. 引入（1-2句）：自然引入话题
2. 传递（3-5句）：分层次传递信息
3. 反应（2-3句）：接收者的反应
4. 行动（1-2句）：基于信息的行动

【注意事项】
- 避免"信息倾倒"
- 用反应展示信息的重要性
- 穿插动作打断节奏
```

## 模板 4：争吵对话

```
【场景设定】
- 争吵原因：
- 双方立场：
- 情绪强度：

【对话结构】
1. 导火索（1句）：引发争吵的事件
2. 升级（3-5句）：情绪逐渐升级
3. 高潮（1-2句）：最伤人的话/最真实的感受
4. 转折（1句）：冷静/反转/外部打断
5. 收尾（1-2句）：情绪落点

【注意事项】
- 短句制造紧张感
- 打断对话增加真实感
- 身体语言比对话更重要
```

---

## 模板 5：沉默对话

```
【场景设定】
- 为什么沉默：
- 沉默的含义：
- 如何打破沉默：

【结构】
1. 沉默（动作描写）：用动作展示情绪
2. 试探（1句）：尝试开口
3. 再沉默（动作描写）：情绪加深
4. 打破（1-2句）：最终开口

【注意事项】
- 沉默本身就是对话
- 用环境音填充空白
- 动作 > 语言
```
