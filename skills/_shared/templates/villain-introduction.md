# 反派出场模板

> 使用方法：根据反派类型选择模板，填充具体内容。

---

## 模板 1：压迫型反派

```
【反派设定】
- 身份/地位：
- 实力等级：
- 核心特质：

【出场结构】
1. 传闻（200-300字）：通过他人描述建立压迫感
2. 初见（300-500字）：外貌 + 气场展示
3. 对峙（500-800字）：与主角的第一次交锋
4. 压制（200-300字）：展示实力差距

【注意事项】
- 压迫感 > 直接战斗
- 用细节展示强大（从容、淡定、不屑）
- 让读者感到绝望
```

## 模板 2：智谋型反派

```
【反派设定】
- 智力水平：
- 策略风格：
- 核心动机：

【出场结构】
1. 布局（300-500字）：展示反派的计划
2. 对话（300-500字）：言语中的机锋
3. 反转（200-300字）：主角发现被骗
```

## 模板 3：悲剧型反派

```
【反派设定】
- 过去经历：
- 转变原因：
- 核心痛苦：

【出场结构】
1. 日常（300-500字）：展示反派的另一面
2. 回忆（200-300字）：过去的创伤
3. 转变（200-300字）：从好人到反派
4. 对峙（300-500字）：与主角的理念冲突

【注意事项】
- 让读者同情反派
- 展示"如果主角是TA会怎样"

```

## 模板 4：镜像型反派

```
【反派设定】
- 与主角的相似点：
- 与主角的差异点：
- 核心冲突：

【出场结构】
1. 相似（300-500字）：展示与主角的相似
2. 差异（300-500字）：展示关键差异
3. 对峙（500-800字）：理念碰撞
4. 选择（200-300字）：主角的选择 vs 反派的选择

【注意事项】
- 反派是主角的"另一面"
- 展示"一念之差"
- 让读者思考"谁才是对的"
```
