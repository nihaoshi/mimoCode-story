# 情感线模板

> 使用方法：根据情感阶段选择模板，填充具体内容。

---

## 模板 1：相识阶段

```
【场景设定】
- 相识方式：偶遇/介绍/冲突
- 第一印象：
- 情感基调：

【结构】
1. 初见（300-500字）：外貌描写 + 第一印象
2. 互动（500-800字）：第一次对话/冲突
3. 留白（200-300字）：分开后的印象

【注意事项】
- 第一印象要具体（不要"他很帅"）
- 用细节展示性格
- 留下悬念/好奇心
```

---

## 模板 2：相知阶段

```
【场景设定】
- 已认识多久：
- 当前关系：
- 情感状态：

【结构】
1. 日常互动（500-800字）：共同经历
2. 深入了解（300-500字）：发现共同点/差异
3. 情感升温（200-300字）：产生好感

【注意事项】
- 用具体事件展示性格
- 避免"日久生情"的俗套
- 制造"只有他们懂"的默契
```

---

## 模板 3：误会阶段

```
【场景设定】
- 误会原因：
- 误会内容：
- 情感伤害：

【结构】
1. 导火索（200-300字）：引发误会的事件
2. 误解（300-500字）：错误的理解
3. 伤害（200-300字）：情感反应
4. 冷战（300-500字）：关系僵持

【注意事项】
- 误会要合理（不是故意制造矛盾）
- 展示双方的委屈
- 读者要比角色更着急
```

---

## 模板 4：和好阶段

```
【场景设定】
- 误会如何解除：
- 谁先低头：
- 情感升华：

【结构】
1. 契机（200-300字）：和好的机会
2. 对话（300-500字）：坦诚沟通
3. 和解（200-300字）：情感释放
4. 升华（200-300字）：关系更进一步

【注意事项】
- 和好要自然（不要强行HE）
- 展示成长和改变
- 保留一点遗憾/不完美
```

---

## 模板 5：分离阶段

```
【场景设定】
- 分离原因：
- 分离方式：
- 情感基调：

【结构】
1. 预感（200-300字）：预感到分离
2. 告别（300-500字）：最后的对话
3. 离开（200-300字）：实际分离
4. 余韵（200-300字）：分离后的情绪

【注意事项】
- 分离要有重量感
- 用细节强化情感（物品、地点、习惯）
- 留下重逢的可能
```
