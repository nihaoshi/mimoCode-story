# 平台审稿规则参考

> 故事批评家（story-critic-mimo）审稿时参考的平台标准。
> 每个平台的读者群体、付费模式和内容偏好不同，审稿标准也随之调整。

---

## 平台速查

| 平台 | 模式 | 核心用户 | 节奏要求 | 字数偏好 | 核心卖点 |
|------|------|---------|---------|---------|---------|
| 起点中文网 | 付费 | 男频老白 | 中慢，可铺垫 | 200-500万字长篇 | 世界观/爽点/力量体系 |
| 番茄小说 | 免费广告 | 下沉+女频多 | 极快，三章定生死 | 100-300万字 | 爽点密度/情绪拉满 |

| 七猫小说 | 免费广告 | 下沉市场 | 快，爽点密 | 100-200万字 | 情绪碾压/快节奏 |

## 起点中文网

### 核心规则

- **男频主站**，读者以老白为主，对套路容忍度低
- **付费模式**：读者每千字付费，所以质量要对得起价格
- **节奏要求**：偏慢但信息量不能少，铺垫期可长达10-20章
- **字数要求**：200万字起步，300-500万字为常规

### 审稿重点

| 维度 | 起点标准 | 严格程度 |
|------|---------|---------|
| 世界观 | 必须完整自洽，不能有逻辑漏洞 | 🔴 极严 |
| 力量体系 | 必须清晰，境界/等级分明 | 🔴 极严 |
| 爽点 | 不追求密集但追求"质量"，每5章一个大爽点 | 🟡 中等 |
| 节奏 | 允许慢热但前20章必须有第一个高潮 | 🟡 中等 |
| 文笔 | 中等偏上，不追求华丽但求流畅 | 🟢 宽松 |
| 创新性 | 必须有一定新意，"换皮文"会被老白弃书 | 🔴 极严 |
| 配角 | 配角要有独立人格，不能是工具人 | 🔴 极严 |

### 扣分项（起点专属）

- 力量体系崩坏（后期战力失控）- P0
- 主角降智（为剧情强行弱化主角）- P0
- 配角工具化（纯粹为主角服务的NPC）- P1
- 节奏太慢且没有信息量（水字数）- P1
- 套路太老（读者一眼看到底）- P1
- 金手指太强破坏平衡- P1

## 番茄小说

### 核心规则

- **免费阅读广告模式**：读者不花钱，所以随时可弃
- **前三章定生死**：前500字抓不住读者就废了
- **节奏极快**：不能有任何废话，每段都要有信息量或情绪价值
- **情绪拉满**：爽文必须是爽文，虐文必须虐到位

### 审稿重点

| 维度 | 番茄标准 | 严格程度 |
|------|---------|---------|
| 开篇钩子 | 前500字必须有冲突或悬念 | 🔴 极严 |
| 爽点密度 | 每2000字至少一个爽点 | 🔴 极严 |
| 情绪强度 | 情绪不能"淡淡的"，必须拉到极致 | 🔴 极严 |
| 节奏 | 极快，无废话，每段至少一个信息点 | 🔴 极严 |
| 章尾钩子 | 每章结尾必须有悬念或期待 | 🔴 极严 |
| 世界观 | 简单易懂，不要复杂设定 | 🟢 宽松 |
| 文笔 | 直白为主，不要华丽修辞 | 🟢 宽松 |

### 扣分项（番茄专属）

- 前三章平淡无钩子 - P0
- 连续2000字无爽点 - P0
- 章节结尾无悬念 - P1
- 开篇铺设定（"在这个世界..."）- P0
- 心理描写过长（超过3段）- P1
- 节奏慢（一章过去了什么也没发生）- P0
- 情绪平淡（不痛不痒的描写）- P1

## 晋江文学城

### 核心规则

- **女频主站**，读者对文笔和感情线要求极高
- **付费模式**：读者精打细算，每章都要值
- **感情线为主**：言情/耽美为核心，剧情服务于感情
- **字数偏好**：中篇为主，30-80万字

### 审稿重点

| 维度 | 晋江标准 | 严格程度 |
|------|---------|---------|
| 文笔 | 必须好，有美感，不能是"大白话" | 🔴 极严 |
| 感情线 | 细腻、有层次、有拉扯 | 🔴 极严 |
| 人物塑造 | 必须有血有肉，不能扁平 | 🔴 极严 |
| 节奏 | 偏慢但信息量充足 | 🟡 中等 |
| 爽点 | 情绪爽（感情向）而非实力爽（升级向） | 🟡 中等 |
| 独特性 | 不能和热门文撞设定，要有差异化 | 🟡 中等 |
| 三观 | 主流三观正，不能有争议性内容 | 🔴 极严 |

### 扣分项（晋江专属）

- 文笔差（句子不通顺/缺乏美感）- P0
- 感情线推进太急/太慢- P1
- 男主形象扁平（霸总模板化）- P0
- 女主是傻白甜（没有成长和主见）- P0
- 配角全是"恶毒女配/深情男二"模板- P1
- 感情没有拉扯（一上来就互相喜欢）- P1
- 剧情线压倒感情线- P1

## 知乎盐选

### 核心规则

- **付费短篇**，信息密度极高
- **开篇悬念**：30字内必须制造悬念
- **篇幅精炼**：1-3万字，容不得任何废话
- **内容偏好**：真实感强、代入感强、有情感冲击力

### 审稿重点

| 维度 | 知乎盐选标准 | 严格程度 |
|------|------------|---------|
| 开篇 | 前30字制造悬念，前100字完成钩子 | 🔴 极严 |
| 信息密度 | 每句话都要有信息量，不能水 | 🔴 极严 |
| 悬念设计 | 必须在开篇就抛出疑问 | 🔴 极严 |
| 情绪冲击 | 结尾要有情绪余韵 | 🔴 极严 |
| 反转 | 必须有反转，最好2-3个 | 🟡 中等 |
| 真实感 | 要让人觉得"可能是真的" | 🔴 极严 |
| 节奏 | 极快，500字一个小高潮 | 🔴 极严 |

### 扣分项（知乎盐选专属）

- 开篇30字无悬念 - P0
- 信息密度低（可砍掉30%字数而不影响理解）- P0
- 无反转或反转太弱 - P1
- 结尾没有情绪余韵 - P1
- 代入感差（"与我无关"的感觉）- P1
- 场景切换太频繁 - P1
- 字数超标（超过3万字的短篇）- P2

## 七猫小说

### 核心规则

- **免费阅读广告模式**，下沉市场为主
- **情绪拉满**：爽就爽到极致，虐就虐到心碎
- **节奏快**：不能有任何拖沓
- **爽点密**：比番茄还密

### 审稿重点

| 维度 | 七猫标准 | 严格程度 |
|------|---------|---------|
| 爽点密度 | 极密，每1500字一个爽点 | 🔴 极严 |
| 情绪强度 | 拉到最满，不能"淡淡的" | 🔴 极严 |
| 节奏 | 极快，无废话 | 🔴 极严 |
| 钩子 | 章章有钩子，句句有信息 | 🔴 极严 |
| 文笔 | 直白接地气，不要文绉绉 | 🟢 宽松 |
| 世界观 | 简单直接，不要复杂 | 🟢 宽松 |

### 扣分项（七猫专属）

- 连续1500字无爽点 - P0
- 情绪平淡（"还好""一般""还行"级别）- P0
- 章节结尾平淡无钩子 - P0
- 开篇铺设定 - P0
- 文笔太文雅（不适合下沉市场）- P1

## 点众

### 核心规则

- **免费阅读**，偏轻松向
- **情感驱动**：女频为主，甜宠/虐恋热门
- **节奏快但偏轻松**：不追求极致爽感，更追求阅读愉悦感

### 审稿重点

| 维度 | 点众标准 | 严格程度 |
|------|---------|---------|
| 阅读愉悦感 | 读起来轻松愉快还是费劲？ | 🔴 极严 |
| 节奏 | 快但不压迫 | 🟡 中等 |
| 爽点 | 温和型爽点（甜/暖/解气） | 🟡 中等 |
| 情绪 | 偏甜暖，不过度虐 | 🟡 中等 |
| 文笔 | 流畅好读即可 | 🟢 宽松 |

### 扣分项（点众专属）

- 阅读门槛高（需要动脑子）- P1
- 情绪压抑过多（不能长时间虐）- P1
- 节奏混乱（忽快忽慢）- P1
- 文笔生涩难懂 - P2

## 不指定平台（通用标准）

当用户不指定目标平台时，使用通用标准+自动推荐最适配平台：

| 维度 | 通用标准 |
|------|---------|
| 结构 | 完整、合理、无硬伤 |
| 人设 | 有血有肉、动机合理、有弧线 |
| 爽点 | 密度适中、类型多样、铺垫到位 |
| 钩子 | 开篇和章末有钩子 |
| 情绪 | 有起伏、有节奏、有释放 |
| 文笔 | 流畅、无AI味、对话自然 |
| 商业化 | 题材有市场、有差异化卖点 |
| 一致性 | 无矛盾、伏笔有回收 |

通用标准不涉及平台具体适配，但会在报告末尾给出平台推荐及理由。
