# pre-write-load

## 功能
写前准备，自动加载写作所需的全部上下文信息，包括细纲、追踪文件、设定文件和对标资料。

## 双模执行
- **独立模式**：输入为空时，自动检测当前进度，加载全部所需文件
- **编排器模式**：输入不为空时，根据 {chapter_number} 和 {load_items} 指定加载

## 执行步骤

### 1. 确定当前章节
- 如果 {chapter_number} 为 "auto"，从 `追踪/上下文.md` 读取当前进度
- 否则使用传入的 {chapter_number}

### 2. 加载细纲
- 读取 `大纲/细纲_第{N}章.md`（本章细纲）
- 读取 `大纲/细纲_第{N-1}章.md`（上一章细纲）
- 读取 `大纲/细纲_第{N-2}章.md`（前二章细纲）
- 读取 `大纲/细纲_第{N-3}章.md`（前三章细纲）

### 3. 加载追踪文件
读取 `追踪/` 目录下所有文件：
- `追踪/伏笔.md`
- `追踪/时间线.md`
- `追踪/角色状态.md`
- `追踪/物品.md`
- `追踪/环境.md`
- `追踪/物资.md`
- `追踪/重复语句.md`
- `追踪/上下文.md`
- `追踪/cross-chapter-fingerprint.md`

### 4. 加载设定文件
读取 `设定/` 目录下所有文件：
- `设定/世界观.md`
- `设定/势力.md`
- `设定/金手指.md`
- `设定/等级体系.md`
- `设定/题材定位.md`

### 5. 加载对标资料（如有）
- 检查 `对标/` 目录是否存在
- 如果存在，读取与当前题材/类型相关的对标文件

### 6. 格式化输出
按以下结构输出：

```
═══════════════════════════════════════════
📝 写前准备报告 — 第{N}章
═══════════════════════════════════════════

【本章细纲】
{细纲内容摘要}

【前三章回顾】
- 第{N-1}章：{核心事件}
- 第{N-2}章：{核心事件}
- 第{N-3}章：{核心事件}

【追踪状态】
- 待回收伏笔：{N}个
- 角色状态：{摘要}
- 时间线：当前位置
- 物品：{关键物品}

【设定摘要】
- 世界观：{核心设定}
- 势力：{当前势力格局}
- 金手指：{当前能力等级}

【对标参考】
- {对标文件名}：{核心技法}

【写作建议】
- 基于以上信息，建议本章重点：
  1. {建议1}
  2. {建议2}
  3. {建议3}

═══════════════════════════════════════════
```
