# 情绪指导注入

> 写作时强制执行，确保情绪有起伏、有节奏、有爽点。

---

## 情绪注入协议

### 写作前必须明确（从细纲读取）

在开始写作前，必须从细纲中提取以下情绪信息：

1. **本章情绪弧线类型**：V型/W型/递进型/延迟满足型/倒V型/急转型
2. **情绪强度范围**：低谷X/10 → 高峰Y/10
3. **爽点位置**：章末80%/章中50%/章头20%
4. **压制手段**：（具体写出本章用什么方式压制主角）
5. **释放方式**：（具体写出本章用什么方式释放情绪）

### 情绪弧线速查

| 弧线类型 | 适用场景 | 核心节奏 |
|---------|---------|---------|
| V型 | 虐完翻盘 | 谷底60-70%，治愈急速回升 |
| 倒V型 | 甜完刀死（BE） | 高点40-50%，坠落比上升快 |
| W型 | 多反转猜不到 | 每峰比前高，上限3起伏 |
| 递进型 | 层层打脸升级 | 无回落，像台阶往上 |
| 延迟满足型 | 隐忍后大爆发 | 前70-80%铺垫，最后集中爆发 |
| 急转型 | 结尾颠覆 | 70-80%处急转弯 |

## 写作时必须执行

### 压制段写作要求

- **情绪密度高**：短句密集，五感聚焦负面
- **氛围压抑**：环境描写偏暗、偏冷、偏静
- **角色状态**：受伤、被误解、被压制、孤立无援
- **读者感受**：憋屈、愤怒、心疼、想打人

**示例**：
```
他攥紧拳头，指甲掐进肉里。
血从指缝渗出来，滴在地上。
没有人说话。
整个大厅安静得能听见自己的心跳。
```

### 释放段写作要求

- **节奏加快**：动作描写多，短句连击
- **氛围转亮**：环境描写偏亮、偏热、偏响
- **角色状态**：反击、翻盘、碾压、打脸
- **读者感受**：爽、解气、拍桌子、截图分享

**示例**：
```
"你说什么？"他笑了。
笑得很轻，很淡。
然后他站了起来。
整个大厅的温度骤降。
"我再说一遍。"
他的声音不大，但每个人都听得清清楚楚。
"跪下。"
```

### 过渡段写作要求

- **环境描写+内心活动**：调节呼吸
- **节奏放缓**：长句、景物、回忆
- **情绪缓冲**：从高压到释放的过渡
- **读者感受**：喘息、期待、好奇

**示例**：
```
窗外的雨还在下。
他坐在椅子上，看着杯子里的茶叶慢慢沉下去。
茶已经凉了。
他没有喝。
```

## 硬约束（违规即修复）

### 情绪起伏约束

1. **连续3段相同强度同类情绪 = 违规**
   - 解法：插入不同类型的情绪，或调整强度

2. **只有压制没有释放 = 违规**
   - 解法：在章末或关键节点加入释放

3. **只有释放没有压制 = 违规**
   - 解法：在释放前加入压制铺垫

4. **情绪强度波动<2点连续3章 = 违规**
   - 解法：增加情绪起伏，制造波峰波谷

### 爽点密度约束

| 题材 | 建议间距 | 最大容忍间距 |
|------|---------|------------|
| 番茄/短篇 | 每1500-2000字 | 3000字 |
| 起点/长篇 | 每3000-5000字 | 8000字 |
| 晋江/言情 | 每2000-3000字 | 5000字 |
| 悬疑/惊悚 | 每2000-4000字 | 6000字 |

超过最大容忍间距 → 读者流失风险显著上升。

### 情绪三层分离

写每个场景时分离三层情绪：

1. **角色自己的情绪**（角色感受到的）
2. **文本传递的情绪**（文本要让读者感受的）
3. **读者实际感受的情绪**（读者真正的体验）

同一场景三层可以完全不同：
- 角色在哭，文本在撩，读者在爽
- 角色在笑，文本在虐，读者在哭

## 情绪检测清单

写完每章后逐项检查：

### 弧线选择与节奏
- [ ] 弧线类型是否匹配你想写的情绪效果？
- [ ] 关键转折点是否在正确的进度位置？
- [ ] 字数分配是否符合所选弧线的比例要求？

### 调动与释放
- [ ] 每个场景是否清楚当前是"调动"还是"释放"阶段？
- [ ] 是否存在只有调动没有释放的段落？（会憋屈弃书）
- [ ] 是否存在只有释放没有调动的段落？（爽感平淡）
- [ ] 连续爽点是否逐级递增？

### 期待感
- [ ] 每个目标是否已转化为读者期待？
- [ ] 闭环一个期待时，下一个开环是否已在运行？
- [ ] 感情线是否设置了阻碍？

### 情绪代入
- [ ] 开篇是否用了塑造人物性格的事件？
- [ ] 读者未代入主角前，是否避免了把对手写得可怜？
- [ ] 下行情节中是否给了读者安全感？

## 注入模板

在写作子agent的prompt中注入：

```
【情绪注入】
本章情绪弧线：{弧线类型}
情绪强度：低谷{X}/10 → 高峰{Y}/10
爽点位置：{位置}
压制手段：{具体手段}
释放方式：{具体方式}

【情绪硬约束】
1. 连续3段相同强度同类情绪 = 违规
2. 只有压制没有释放 = 违规
3. 只有释放没有压制 = 违规
4. 超过最大爽点间距 = 违规

【情绪写作指令】
压制段：短句密集，五感聚焦负面，氛围压抑
释放段：节奏加快，动作描写多，氛围转亮
过渡段：环境描写+内心活动，调节呼吸
```
