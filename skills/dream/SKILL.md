# dream-mimo：写作经验沉淀

你是写作经验分析师。从历史写作中提取经验，保存到记忆系统，供后续写作参考。

---

## 触发条件

| 用户说 | 动作 |
|--------|------|
| /dream | 提取近期写作经验 |
| /dream --days 14 | 提取最近14天经验 |
| 提取经验 | 同 /dream |
| 分析一下写作 | 同 /dream |

---

## 执行流程

### Step 1：扫描章节

扫描 `正文/` 目录下所有章节文件，默认扫描最近10章。

### Step 2：分析模式

调用 `_shared/scripts/dream.js` 分析：

```bash
node skills/_shared/scripts/dream.js <项目目录> --days 7
```

**分析内容**：
- 禁用词频率（不禁、竟然、事实上等）
- AI腔模式（章末预告体、升华式结尾、万能比喻）
- 有效技法（对话驱动、动作叙事、段落节奏）
- 句式重复（连续相同开头）

### Step 3：写入记忆

将分析结果写入 `MEMORY.md`：

```markdown
## 写作经验 (YYYY-MM-DD)

### 需要注意的问题
- banned_word: "不禁" 出现 5 次
- ai_pattern: "章末预告体" 出现 2 次

### 有效的技法
- 对话驱动：使用 10 次
- 动作叙事：使用 8 次
```

### Step 4：输出报告

向用户展示经验提取结果：

```
💡 写作经验提取完成

⚠️ 需要注意的问题：
- 禁用词"不禁"出现5次
- 句式"陈玄说"重复15次

✅ 有效的技法：
- 对话驱动：10次
- 动作叙事：8次

经验已保存到 MEMORY.md
```

## 经验类型

| 类型 | 说明 | 处理方式 |
|------|------|---------|
| 禁用词 | 高频AI词汇 | 记录，后续写作避免 |
| AI腔 | AI写作模式 | 记录，去AI味时重点检查 |
| 有效技法 | 成功的写作手法 | 记录，后续写作复用 |
| 句式重复 | 重复的句子开头 | 记录，建议变换 |
