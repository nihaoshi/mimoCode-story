# 章内逻辑性检查规则

> 检查章节内事件的逻辑连贯性，发现问题必须标记为 WARN

---

## 检查维度

### 1. 时间逻辑

检查事件发生的时间顺序是否合理。

**检查项**：
- 事件发生顺序是否符合时间线
- 是否有时间跳跃未交代
- 时间描述是否前后一致
- 相对时间表述是否准确（"之后"、"同时"、"之前"）

**常见问题**：
- 角色在 A 场景说"明天"，B 场景却在同一天发生
- 事件描述为"几小时后"，但上下文暗示时间更短
- 同一场景内时间流逝不合理

### 2. 因果逻辑

检查事件之间是否有因果关系。

**检查项**：
- 事件 A 是否导致事件 B
- 角色行为是否有明确动机
- 结果是否与原因匹配
- 是否有无因之果

**常见问题**：
- 角色突然改变态度，无铺垫
- 问题突然解决，无过程
- 事件转折缺乏铺垫

### 3. 角色逻辑

检查角色行为是否符合性格设定。

**检查项**：
- 行为是否符合角色性格
- 对话是否符合角色说话风格
- 决策是否符合角色动机
- 情绪变化是否合理

**常见问题**：
- 谨慎角色突然冒险
- 内向角色突然健谈
- 角色做出违背设定的行为

### 4. 空间逻辑

检查场景转换是否合理。

**检查项**：
- 场景转换是否有交代
- 角色位置是否前后一致
- 空间关系是否清晰
- 移动时间是否合理

**常见问题**：
- 角色瞬间移动到另一地点
- 场景描述与前文矛盾
- 空间关系混乱

### 5. 动机逻辑

检查角色行动是否有明确动机。

**检查项**：
- 角色行动是否有理由
- 目标是否清晰
- 手段是否合理
- 结果是否符合预期

**常见问题**：
- 角色无理由地做某事
- 行动与目标不匹配
- 手段过于突兀

---

## 检查方法

### Step 1: 提取事件序列

从正文中提取所有事件，按时间顺序排列：

```
事件1: 时间 + 地点 + 人物 + 内容
事件2: 时间 + 地点 + 人物 + 内容
...
```

### Step 2: 检查事件关系

检查相邻事件之间的关系：
- 时间关系：是否连续、是否有跳跃
- 因果关系：是否有因果
- 空间关系：是否在同一地点或合理转换

### Step 3: 检查角色行为

检查每个角色的行为是否符合设定：
- 对照角色状态文件中的性格锚点
- 检查行为是否有铺垫
- 检查对话是否符合说话风格

### Step 4: 标记问题

发现问题时，按以下格式标记：

```json
{
  "type": "time|cause|character|space|motivation",
  "severity": "WARN",
  "location": "场景X / 第Y段",
  "description": "问题描述",
  "suggestion": "修复建议"
}
```

---

## 输出格式

```json
{
  "chapter": 21,
  "logic_issues": [
    {
      "type": "cause",
      "severity": "WARN",
      "location": "场景2",
      "description": "江晨突然决定冒险，缺乏铺垫",
      "suggestion": "在场景1增加江晨内心挣扎的描写"
    }
  ],
  "logic_score": 85,
  "issue_count": 1,
  "overall": "WARN"
}
```

---

## 严重度定义

| 严重度 | 定义 | 处理 |
|--------|------|------|
| WARN | 逻辑问题影响阅读体验 | 必须修复 |
| BLOCK | 逻辑硬伤导致故事不通 | 必须修复 |

**关键规则**：只要有问题（WARN 或 BLOCK），就必须进入修复流程。
