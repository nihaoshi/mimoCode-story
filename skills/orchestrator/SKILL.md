# orchestrator：写作流程编排器

代码控制整个写作流程，AI 只负责生成内容。

**核心原则：AI 不管流程，只管创作。**

---

## 架构

```
编排器（orchestrator.js）
├── 读取细纲
├── 读取追踪文件
├── 调用 AI 生成内容
├── 质量检查
├── 修复问题
├── 更新追踪文件
└── 继续下一章

AI（子智能体）
└── 只负责生成正文内容
```

## 用法

```bash
# 初始化项目
node skills/orchestrator/orchestrator.js <项目目录> init

# 查看进度
node skills/orchestrator/orchestrator.js <项目目录> status

# 写指定章节（完整流程）
node skills/orchestrator/orchestrator.js <项目目录> write <章节号>
```

## 流程

```
写第N章
├── 1. 读取细纲
├── 2. 读取上一章
├── 3. 读取追踪文件（伏笔/角色/物品/环境/重复语句）
├── 4. 调用AI生成内容
├── 5. 质量检查（禁用词/字数/重复语句）
├── 6. 自动修复（禁用词替换）
├── 7. 保存正文
├── 8. 更新追踪文件
└── 9. 继续下一章
```

## AI 只负责

- 生成正文内容
- 生成大纲（可选）
- 设计角色（可选）

## 代码负责

- 流程控制
- 质量检查
- 文件管理
- 追踪更新
- 禁用词修复
- 重复语句检测

## 与原有 skill 的区别

| 原有方式 | 编排器方式 |
|---------|-----------|
| AI 读 SKILL.md | 代码读配置 |
| AI 创建任务 | 代码创建任务 |
| AI 判断跳过 | 代码判断跳过 |
| AI 执行所有步骤 | AI 只生成内容 |
| 容易偷懒跳步 | 代码强制执行 |
