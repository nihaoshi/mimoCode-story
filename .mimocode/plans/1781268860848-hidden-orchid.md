# 计划：将 Writing Project Rules 部署到用户写作项目

## 问题分析

当前 AGENTS.md 中定义了 Writing Project Rules（写作项目强制规则），但这些规则**没有自动部署到用户写作项目中**：

1. `story-setup` skill 创建项目结构时**不创建 AGENTS.md**
2. 没有任何 skill 引用 AGENTS.md
3. 用户需要手动将 Writing Project Rules 复制到自己的写作项目中

## 解决方案

修改 `skills/story-setup/SKILL.md`，在 Phase 3 部署基础设施时，自动在用户写作项目根目录创建 AGENTS.md 文件。

## 修改文件

### 1. `skills/story-setup/SKILL.md`

在 Phase 3（部署基础设施）中新增步骤：

**在 Phase 3.3 之后添加 Phase 3.4：创建项目 AGENTS.md**

```
### 3.4 创建项目 AGENTS.md

在写作项目根目录创建 AGENTS.md，包含 Writing Project Rules。
内容从本仓库的 AGENTS.md 中提取 Writing Project Rules 部分。
```

AGENTS.md 内容模板（从本仓库 AGENTS.md 第 46-113 行提取）：

```markdown
# AGENTS.md

## Writing Project Rules（写作项目强制规则）

[完整复制 AGENTS.md 第 46-113 行的内容]
```

### 2. 调整后续步骤编号

原 3.4 → 3.5，原 3.5 → 3.6

## 验证方式

1. 在空目录运行 `/story-setup`
2. 检查创建的写作项目目录中是否存在 AGENTS.md
3. 验证 AGENTS.md 包含完整的 Writing Project Rules
4. 验证 AI 在新会话中能自动读取这些规则
