# 章节生成功能 - 实现计划

> 代码控制整个流程，AI 只在生成内容时调用

---

## 一、功能概述

### 1.1 核心原则

```
代码负责：读取文件、流程控制、质量检查、追踪更新
AI 负责：生成正文内容（唯一调用点）
```

### 1.2 流程图

```
用户点击"生成第N章"
    ↓
代码：读取细纲
    ↓
代码：读取上一章
    ↓
代码：读取追踪文件（伏笔/角色/物品/环境/重复语句）
    ↓
代码：构建 prompt
    ↓
AI：生成正文内容 ← 唯一调用点
    ↓
代码：质量检查（禁用词/字数/一致性）
    ↓
代码：自动修复（禁用词替换）
    ↓
代码：保存正文
    ↓
代码：更新追踪文件
    ↓
完成
```

## 二、实现计划

### 2.1 创建章节生成器

**文件**：`skills/orchestrator/chapter-generator.js`

**功能**：
- 读取上下文（16项）
- 构建 prompt
- 调用 AI
- 质量检查
- 自动修复
- 保存正文
- 更新追踪

**流程**：
```javascript
class ChapterGenerator {
  async generate(chapterNum) {
    // 1. 读取上下文
    const context = await this.readContext(chapterNum);
    
    // 2. 构建 prompt
    const prompt = this.buildPrompt(context);
    
    // 3. 调用 AI（唯一调用点）
    const content = await this.callAI(prompt);
    
    // 4. 质量检查
    const issues = await this.checkQuality(content);
    
    // 5. 自动修复
    const fixed = await this.autoFix(content, issues);
    
    // 6. 保存正文
    await this.saveChapter(chapterNum, fixed);
    
    // 7. 更新追踪
    await this.updateTracking(chapterNum, fixed);
  }
}
```

### 2.2 实现步骤

#### Step 1: 读取上下文（代码）

```javascript
async readContext(chapterNum) {
  return {
    // 必需
    outline: await readFile(`大纲/细纲_第${chapterNum}章.md`),
    previousChapter: await readFile(`正文/第${chapterNum-1}章_*.md`),
    
    // 追踪文件
    foreshadows: await readFile(`追踪/伏笔.md`),
    characterStates: await readFile(`追踪/角色状态.md`),
    items: await readFile(`追踪/物品.md`),
    environment: await readFile(`追踪/环境.md`),
    blacklist: await readFile(`追踪/重复语句.md`),
    
    // 可选
    styleGuide: await readFile(`设定/文风.md`),
    benchmark: await readFile(`对标/拆文报告.md`),
  };
}
```

#### Step 2: 构建 prompt（代码）

```javascript
buildPrompt(context) {
  return `你是一个网文写手。请根据以下信息写第{N}章正文。

## 细纲
${context.outline}

## 上一章摘要
${context.previousChapter?.slice(0, 500) || '无（第一章）'}

## 角色状态
${context.characterStates}

## 待回收伏笔
${context.foreshadows}

## 重复语句黑名单（禁止使用）
${context.blacklist || '无'}

## 禁用词（禁止使用）
${BANNED_WORDS.join('、')}

## 要求
1. 严格按照细纲的情节点序列写作
2. 字数目标：${context.outline.match(/字数目标：(\d+)/)?.[1] || 3000}字
3. 不要使用黑名单中的语句
4. 不要使用禁用词
5. 直接输出正文，不要有其他内容

请写第{N}章正文：`;
}
```

#### Step 3: 调用 AI（唯一调用点）

```javascript
async callAI(prompt) {
  // 支持多种 AI 提供商
  const provider = this.config.aiProvider;
  
  switch (provider) {
    case 'openai':
      return await this.callOpenAI(prompt);
    case 'anthropic':
      return await this.callAnthropic(prompt);
    case 'local':
      return await this.callLocal(prompt);
  }
}
```

#### Step 4: 质量检查（代码）

```javascript
async checkQuality(content) {
  const issues = [];
  
  // 禁用词检查
  for (const word of BANNED_WORDS) {
    if (content.includes(word)) {
      issues.push({
        type: 'banned-word',
        word,
        severity: 'block'
      });
    }
  }
  
  // 字数检查
  const wordCount = content.length;
  if (wordCount < targetWords * 0.9) {
    issues.push({
      type: 'word-count',
      count: wordCount,
      target: targetWords,
      severity: 'block'
    });
  }
  
  // 重复语句检查
  for (const phrase of blacklist) {
    if (content.includes(phrase)) {
      issues.push({
        type: 'repeat',
        phrase,
        severity: 'warn'
      });
    }
  }
  
  return issues;
}
```

#### Step 5: 自动修复（代码）

```javascript
async autoFix(content, issues) {
  let fixed = content;
  
  for (const issue of issues) {
    if (issue.type === 'banned-word') {
      fixed = fixed.replaceAll(issue.word, REPLACEMENTS[issue.word]);
    }
  }
  
  return fixed;
}
```

#### Step 6: 保存正文（代码）

```javascript
async saveChapter(chapterNum, content) {
  const filename = `第${String(chapterNum).padStart(3, '0')}章.md`;
  await writeFile(`正文/${filename}`, content);
}
```

#### Step 7: 更新追踪（代码）

```javascript
async updateTracking(chapterNum, content) {
  // 更新上下文
  await this.updateContext(chapterNum);
  
  // 更新重复语句（如有新发现）
  await this.updateRepeatSentences(chapterNum, content);
}
```
