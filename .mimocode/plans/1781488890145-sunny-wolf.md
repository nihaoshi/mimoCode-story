# 跨章节重复检测方案（Skill 自动调用）

## 问题

1. 当前质量门禁（quality-gate.js）是**手动 node 调用**，不在 skill 自动流程中
2. 跨章的句子/段落/动作/场景重复完全无法检测
3. 用户希望通过 **skill 自动调用**，而非手动执行命令

## 方案：Skill 自动化 + 滑动窗口 n-gram

### 架构设计

```
用户说"写下一章"
    ↓
story-long-write-mimo Skill 自动执行
    ↓
Phase 4 写作
    ├─ Step 2: 读取上下文（含前 5 章指纹）
    ├─ Step 3: 准备层（含跨章重复预检）
    ├─ Step 6-7: 写作
    └─ Step 8-12: 自动检查（含跨章重复检测）
    ↓
Phase 5 质量检查
    └─ 自动运行 quality-gate.js（含 cross-chapter-check）
```

### 关键改动

1. **新建 `cross-chapter-check.js`**：跨章重复检测脚本
2. **修改 `quality-gate.js`**：集成 cross-chapter-check 作为第 8 项检查
3. **修改 `story-long-write-mimo/SKILL.md`**：
   - Phase 4 Step 2 新增指纹文件读取
   - Phase 4 Step 3 新增跨章重复预检
   - Phase 4 Step 12 新增自动调用 quality-gate.js
4. **修改 `story-short-write-mimo/SKILL.md`**：同步更新

---

## 实施步骤

### Step 1：新建 `cross-chapter-check.js`

**路径**：`skills/story-long-write-mimo/scripts/cross-chapter-check.js`

**功能**：
- 输入：当前章节文件 + 项目目录
- 读取：当前章 + 前 5 章（按文件名排序）
- 检测 3 类重复：
  1. **句子级重复**：6 字以上子串在其他章节出现 ≥2 次
  2. **段落级重复**：连续 2+ 句子结构相同
  3. **高频动作重复**：相同动作描写在近 5 章重复 ≥3 次

**输出**：标准 JSON（与其他脚本一致）

```json
{
  "status": "pass|warn",
  "file": "当前章节",
  "summary": { "sentence_dupes": 0, "paragraph_dupes": 0, "action_dupes": 0 },
  "issues": [
    { "type": "sentence", "level": 1, "text": "重复片段...", "chapters": ["第3章", "第5章"] }
  ]
}
```

### Step 2：集成到 `quality-gate.js`

**修改文件**：`skills/story-long-write-mimo/scripts/quality-gate.js`

**改动量**：约 30 行

1. 新增 `--skip-cross-chapter` 和 `--window N`（默认 5）参数
2. 在 wordcount 检查之后、voice 检查之前，调用 `cross-chapter-check.js`
3. 结果写入 `results.cross_chapter`

### Step 3：修改 `story-long-write-mimo/SKILL.md`

**Phase 4 Step 2 读取上下文** 新增：

```
- (15) `追踪/cross-chapter-fingerprint.md`（自动生成）— 前 5 章的 n-gram 指纹摘要
```

**Phase 4 Step 3 准备层 3.2 模块召回** 新增：

```
- (e) **跨章重复预检**：读取前 5 章指纹，写作时避免重复以下内容：
  - 重复的句子片段（列出 top 5）
  - 重复的动作描写（列出 top 5）
  - 重复的场景描述（列出 top 5）
```

**Phase 4 Step 12 中途快照** 修改为：

```
12. **中途快照 + 质量门禁**（长篇写作安全网）：
    - 每连续写完 3 章，执行以下操作：
    - (a) 将当前进度写入 `追踪/上下文.md`
    - (b) 用 `ls -la 正文/` 确认最近 3 个章节文件已成功写入
    - (c) **自动运行质量门禁**：`node skills/story-long-write-mimo/scripts/quality-gate.js <章节文件> --json`
    - (d) 如果 status 为 blocked，暂停写作，修复问题后继续
    - (e) 更新 `追踪/cross-chapter-fingerprint.md` 指纹文件
```

### Step 4：修改 `story-short-write-mimo/SKILL.md`

**Phase 4 精修打磨** 新增：

```
#### 自动质量门禁

每节写完后自动运行质量门禁：

```bash
# 自动检查（含跨章重复检测）
node skills/story-short-write-mimo/scripts/quality-gate.js <文件> --json
```

如果 status 为 blocked，暂停写作，修复问题后继续。
```

### Step 5：指纹文件自动生成

在 `cross-chapter-check.js` 中，检查完成后自动生成/更新 `追踪/cross-chapter-fingerprint.md`：

```markdown
# 跨章指纹（自动生成，勿手动编辑）

## 最近 5 章指纹
- 第005章: 623 个 n-gram
- 第004章: 589 个 n-gram
- ...

## 高频重复片段（≥2次）
- "他攥紧了拳头" (3次: 第3/4/5章)
- "阳光透过窗帘" (2次: 第2/5章)
- ...

## 高频重复动作（≥3次）
- 攥紧拳头: 5次
- 深吸一口气: 4次
- ...
```

## 自动化流程

### 长篇写作（story-long-write-mimo）

```
用户: "续写"
    ↓
Skill 自动执行 Phase 4
    ↓
Step 2: 读取上下文（含前 5 章指纹）
    ↓
Step 3: 准备层（含跨章重复预检）
    ↓
Step 6-7: 写作正文
    ↓
Step 8: 字数验证（自动）
    ↓
Step 10: 禁用词扫描（自动）
    ↓
Step 12: 中途快照 + 质量门禁（自动）
    ├─ quality-gate.js 运行
    │   ├─ style-lint
    │   ├─ consistency-check
    │   ├─ foreshadow-check
    │   ├─ wordcount
    │   ├─ cross-chapter-check ← 新增
    │   ├─ voice-check
    │   ├─ emotion-analyzer
    │   └─ satisfaction-meter
    └─ 如果 blocked → 暂停，修复后继续
```

### 短篇写作（story-short-write-mimo）

```
用户: "继续写"
    ↓
Skill 自动执行 Phase 3-4
    ↓
Phase 3: 逐场景写作
    ↓
Phase 4: 精修打磨
    ├─ quality-gate.js 运行（自动）
    │   └─ cross-chapter-check ← 新增
    └─ 如果 blocked → 暂停，修复后继续
```

---

## 验证方式

1. 在写作项目中写 3 章内容（故意重复一些句子/动作）
2. **自动验证**：Skill 执行到 Step 12 时会自动运行 quality-gate.js
3. 查看输出：`details.cross_chapter` 字段应包含重复检测结果
4. 如果有重复，quality-gate 会返回 status: "warn"，Skill 会提示用户

**无需手动运行 node 命令**，全部由 Skill 自动触发。
