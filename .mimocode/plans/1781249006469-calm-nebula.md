# 深度整合 MiMo Code 能力 + 强制参考加载 + 项目 Agent 说明

## 核心思路

问题：60 个参考文档，AI 大概率跳过。解决方案不是"全部塞进上下文"（会爆），而是**分层强制加载 + agent 分担**。

## 分层加载策略

| 层级 | 时机 | 内容 | 强制方式 |
|------|------|------|---------|
| **L0 常驻** | 每次会话 | AGENTS.md 中的核心规则 + 禁用词表 + 快速参考摘要 | MiMo Code 自动注入 |
| **L1 阶段必读** | Phase 1-5 各阶段开始 | 该阶段对应的参考文件（见下表） | SKILL.md 中标记"必读" |
| **L2 按需加载** | 写具体场景时 | 对话/打斗/情感等技法参考 | SKILL.md 中标记"按需" |

### L0：AGENTS.md 常驻内容（~3000 字，MiMo Code 每次会话自动加载）

在 AGENTS.md 中添加：
- 一级禁用词表（30 个词，从 banned-words.md 内联）
- 每章必做的追踪更新清单（checkbox 格式）
- 核心写作铁律（5 条）
- 参考文档快速索引（按场景→文件名映射，从 INDEX.md 精简）

### L1：阶段必读参考（SKILL.md 中标记为"必读，不得跳过"）

| Phase | 必读参考 | 文件大小 | 为什么必读 |
|-------|---------|---------|-----------|
| Phase 1 选题 | `genre-catalog.md` | 中 | 不读不知道题材分类 |
| Phase 2 设定 | `character-basics.md` | 16KB | 不读角色会扁平 |
| Phase 2 设定 | `genre-core-mechanics.md` | 中 | 不读核心梗会跑偏 |
| Phase 3 大纲 | `outline-methods.md` | 中 | 不读大纲会散 |
| Phase 3 大纲 | `opening-design.md` | 中 | 黄金三章不读开篇必败 |
| Phase 4 写作 | `hooks-chapter.md` | 中 | 不读钩子会弱 |
| Phase 4 写作 | `dialogue-mastery.md` | 中 | 不读对话会假 |
| Phase 5 检查 | `banned-words.md` | 中 | 不读禁用词会 AI 腔 |

在 SKILL.md 的每个 Phase 开头，把这些从"按需加载"改为"**必须加载**"。

### L2：按需加载（保持现状）

剩余 ~45 个参考文件保持按需加载。这些是进阶技法（反转设计、情绪弧线、跨卷追踪等），AI 在需要时会自动检索。

### 任务 4：workflow-daily.md 添加 Task + Memory 集成

**文件**：`skills/story-long-write/references/workflow-daily.md`

在 Step 2 逐章循环中添加：

```markdown
#### Task 追踪（MiMo Code 原生）
每章开始前：
  task create "写第{N}章：{章名}" → 拿到 TID
  task start {TID}

每章写完后：
  task done {TID}

#### Memory 读写（跨会话持久化）
日更开始时（Step 1）：
  memory({ operation: "search", query: "writing-progress", scope: "projects" })
  → 恢复上次进度

日更结束时（Step 4）：
  将本次写完的章节号、关键决策、待处理事项写入 memory
```

### 任务 5：项目级 Agent 说明文件

**文件**：新增 `skills/story-long-write/references/agent-guide.md`

说明 MiMo Code 项目中如何使用子智能体：

```markdown
# 项目 Agent 使用指南

## MiMo Code 子智能体

MiMo Code 的 actor 工具可以 spawn 子智能体执行独立任务。
本写作系统中以下场景建议使用子智能体：

### 并行拆文（story-long-analyze）
同时拆解多本书的对标分析：
  actor spawn → "拆解《XXX》黄金三章"

### 多视角审稿（story-review）
从不同角度并行审稿：
  actor spawn → "从结构角度审查第15-20章"
  actor spawn → "从人物角度审查第15-20章"

### 资料研究（story-long-write 写作中）
遇到需要查证的外部事实时：
  actor spawn → "研究明朝科举制度的细节"

## 不需要自定义 Agent 文件

MiMo Code 不需要 `.claude/agents/` 目录。
所有子智能体通过 actor 工具动态创建，无需预定义 agent 文件。
```
