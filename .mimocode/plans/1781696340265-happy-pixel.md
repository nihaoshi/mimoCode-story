## 三、设计方案：增加子 agent 处理对标文件

### 新增 Step 04.5: 对标文件处理 [子 agent 隔离]

**位置**：在 Step 04 创建细纲之后，Step 05 文件分析之前

**触发条件**：检查是否存在对标目录或拆文库目录
- 有 → 启动子 agent 处理
- 无 → 跳过，不阻断

**子 agent 职责**：
1. 读取 `设定/题材定位.md` 的「主对标书」字段
2. 确定对标书路径（优先 `对标/{书名}/`，回退 `拆文库/{书名}/`）
3. 读取对标文风.md，提取原文锚点片段
4. 读取拆文报告.md，提取可借鉴套路
5. 读取本章涉及角色的角色档案
6. 输出：`.workflow/step04-benchmark.json`

**输出格式**：
```json
{
  "has_benchmark": true,
  "benchmark_book": "我在大明长生久视",
  "benchmark_path": "对标/我在大明长生久视/",
  "style_profile": {
    "anchor_excerpts": ["原文片段1...", "原文片段2..."],
    "sentence_distribution": "短句为主，平均15字",
    "dialogue_technique": "潜台词率60%，标签率30%"
  },
  "report_insights": {
    "top_techniques": ["技巧1", "技巧2"],
    "top_patterns": ["套路1", "套路2"],
    "avoid_items": ["不建议1", "不建议2"]
  },
  "character_refs": {
    "江晨": {"personality_anchor": "...", "arc": "..."}
  },
  "storyline_ref": {
    "foreshadow_chains": ["伏笔链1", "伏笔链2"]
  }
}
```

### 修改 Step 08 读取上下文

**增加读取**：`.workflow/step04-benchmark.json`（如存在）

**输出到**：`step08-context.json` 的 `benchmark` 字段

### 修改 Step 09 生成约束

**增加处理**：从 benchmark 提取写作约束
- 原文锚点片段 → 作为 few-shot 示范
- 可借鉴套路 → 设计剧情时参考
- 写法技巧 → 写作时参考

**输出到**：`step09-constraints.json` 的 `benchmark_constraints` 字段
