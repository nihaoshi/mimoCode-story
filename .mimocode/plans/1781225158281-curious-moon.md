# 将写作技能安装到 MiMo Code build 模式

## 问题

当前技能只安装到了 compose 目录（`C:\Users\16591\.local\share\mimocode\compose\0.1.0\skills\`），只能在 compose 模式使用。需要同时安装到 build 模式（默认模式）。

## 解决方案

### 1. 修改 openclaw.json 配置

在 `C:\Users\16591\.qclaw\openclaw.json` 的 main agent skills 列表中添加写作技能：

```json
"skills": [
  // ... 现有技能 ...
  "story",
  "story-long-write",
  "story-short-write",
  "story-long-analyze",
  "story-short-analyze",
  "story-long-scan",
  "story-short-scan",
  "story-scan",
  "story-import",
  "story-deslop",
  "story-review",
  "story-cover",
  "story-setup",
  "browser-cdp"
]
```

### 2. 确认技能文件位置

技能文件需要在 MiMo Code 能找到的路径。当前已安装到：
- `C:\Users\16591\.local\share\mimocode\compose\0.1.0\skills\`

### 3. 验证

重启 MiMo Code 后，在 build 模式下测试 `/story` 命令是否可用。

## 执行步骤

1. 备份 `C:\Users\16591\.qclaw\openclaw.json`
2. 在 main agent 的 skills 数组末尾添加 14 个写作技能
3. 重启 MiMo Code
4. 测试 `/story` 命令
