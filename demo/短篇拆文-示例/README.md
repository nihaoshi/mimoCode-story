# 短篇拆文示例

本示例展示如何使用 `story-short-analyze` 拆解一篇短篇小说。

## 使用方式

```
/story-short-analyze
请拆解这篇短篇：[贴入原文或提供文件路径]
```

## 拆文报告示例

以下是一个假设的拆文报告输出示例：

---

## 短篇拆文报告

### 基本信息
- 标题：《深夜来电》
- 字数：8500字
- 平台：知乎盐言故事
- 题材：悬疑/情感

### 故事核
- 核心情绪：细思极恐 + 共鸣感动
- 一句话梗概：女主接到已故母亲的电话，发现母亲死前一直在保护她
- 反转类型：视角反转（读者以为是鬼故事，实际是亲情故事）

### 五维评分
- 开头吸引力：9/10 — 信息差钩子，第一句就抓人
- 情绪张力：8/10 — 恐惧→疑惑→感动，曲线完整
- 反转效果：9/10 — 反转位置合理（>60%），铺垫充分
- 文笔质量：7/10 — 略有AI腔，但整体流畅
- 余韵深度：8/10 — 结尾金句有力

### 情绪曲线
```
开头 ████████░░ 恐惧（8）
铺垫 ██████████ 恐惧峰值（10）
过渡 ██████░░░░ 疑惑（6）
反转 ██████████ 感动峰值（10）
结尾 ████████░░ 余韵（8）
```

### 关键技法

1. **信息差钩子**：开篇「我死后的第三天，老公发了一条朋友圈」，读者比角色知道更多信息
2. **延迟揭示**：母亲的真正死因直到第4节才揭示，铺垫了3条线索
3. **物件钩子**：手机作为核心物件，贯穿全文，第1现（母亲的旧手机）→第2现（发现通话记录）→第3现（手机里的录音）

### 可借鉴套路

1. **开头模式**：信息差+悬念句，适合悬疑/情感类
2. **反转结构**：表面是A故事（恐怖），实际是B故事（亲情）
3. **结尾金句**：用一句话点题，引发共鸣

### 写作手法详解

- **POV**：第一人称，代入感强
- **对话**：母亲的电话内容用间接引语，增加神秘感
- **信息控制**：前3节只给碎片信息，第4节才拼出完整真相
- **感官细节**：用「手机发烫」「信号断断续续」等细节增强真实感
