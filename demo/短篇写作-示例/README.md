# 短篇写作示例

本示例展示如何使用 `story-short-write` 从零开始写一篇短篇小说。

## 使用方式

```
/story-short-write
我想写一篇关于「深夜接到已故母亲电话」的短篇
```

## 写作流程示例

### Phase 1：确定情绪目标

用户：「我想写一篇关于母亲的短篇，想让读者哭」

情绪选择：**意难平 + 共鸣感动**

### Phase 2：构思核心框架

```
## 短篇核心框架

### 基本信息
- 标题（暂定）：《最后的电话》
- 目标字数：8000字
- 目标平台：知乎盐言故事
- 情绪目标：读者读完后想给妈妈打电话

### 一句话梗概
我接到已故母亲的电话，才发现她死前一直在偷偷保护我。

### 核心反转
- 反转类型：视角反转
- 反转内容：母亲不是意外死亡，是为了救我而牺牲
- 铺垫线索：
  1. 母亲说「我一直在你身边」
  2. 旧手机里有365条未接来电
  3. 邻居说母亲死前最后句话是「别告诉她」

### 情绪设计
- 开头情绪：恐惧（6）— 深夜接到陌生电话
- 中段情绪：疑惑（4）— 发现是已故母亲的号码
- 反转情绪：震撼（10）— 发现真相
- 结尾情绪：感动（8）— 金句收尾

### 人设速写
- 主角：25岁女白领，独立但疏远母亲
- 关键角色：母亲，50岁，农村妇女，文盲但爱女儿
- 关系：疏远→和解（通过死亡）
```

### Phase 3：小节大纲

```
###1. 深夜来电 | 手机响/陌生号码/接起来是杂音{发现} -> 听到熟悉的声音「是我」{冲突} | 恐惧→疑惑 | 母亲已死3个月 | 信息差钩子 | 旧手机 | 动 | 高 | 800字

###2. 确认身份 | 查看来电显示/确实是母亲号码{发现} -> 回拨无人接听{冲突} | 疑惑→恐惧 | 母亲死前最后通话记录 | 对话钩子 | 手机通话记录 | 动 | 中 | 800字

###3. 记忆闪回 | 回家翻母亲遗物{发现} -> 发现旧手机里365条未接来电{伏笔} | 悲伤→心酸 | 母亲每天都在打电话 | 回忆钩子 | 旧手机 | 静 | 零 | 800字

###4. 真相揭示 | 找邻居问真相{发现} -> 母亲死前最后句话「别告诉她」{冲突} | 震撼→崩溃 | 母亲是为了救我而死 | 反转 | 录音笔 | 动 | 高 | 800字

###5. 金句收尾 | 手机里找到录音{发现} -> 母亲说「我一直在你身边」{递进} | 感动→释然 | 母亲的爱从未离开 | 余韵钩子 | 录音 | 静 | 中 | 800字
```

### Phase 4：正文写作

正文直接写入 `正文.md`，按小节大纲逐节展开。

### Phase 5：精修打磨

按精修清单逐项检查，重点：
- 开头钩子是否够强
- 反转铺垫是否充分
- 结尾余韵是否到位
- AI腔是否清除

---

## 完成门槛

- [ ] 总字数 ≥ 8000
- [ ] 每节 ≥ 800字
- [ ] 节数 = 5节
- [ ] 开头有钩子
- [ ] 反转有铺垫
- [ ] 结尾有余韵
- [ ] 无AI腔
