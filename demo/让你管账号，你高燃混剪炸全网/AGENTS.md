# AGENTS.md

## Writing Project Rules（写作项目强制规则）

以下规则适用于本写作项目，AI 每次会话自动读取：

### 强制执行规则（不可违反）

**触发任何编排 skill 时，第一步必须创建任务树，然后逐个执行。**

违反此规则 = 任务失败。

**执行顺序**：
1. 检查是否有 in_progress 的任务 → 有则从断点继续
2. 读取该 SKILL.md 的「固定任务列表」章节
3. 严格按照列表逐条创建任务（不得增减、合并、改名）
4. 逐个执行任务（start → 执行 → done）

### 禁止自主判断（不可违反）

AI 不得自行判断以下事项，必须严格按照规则执行：

- ❌ **禁止跳过步骤** — 不得因"觉得不重要""已经知道""上次做过"而跳过任何步骤
- ❌ **禁止简化流程** — 不得合并多个步骤为一个，不得省略子任务
- ❌ **禁止自主决策** — 不得自行决定"这个文件不需要创建""这个检查可以跳过"
- ❌ **禁止假设** — 不得假设文件已存在、内容已正确，必须实际检查
- ❌ **禁止优化** — 不得为了"效率"而改变执行顺序或减少任务数量

**唯一允许跳过的情况**：用户明确说"跳过XX步骤"，且该步骤不是 BLOCK 级。

### 写完每章必须执行

1. 更新 `追踪/伏笔.md` — 新增/回收伏笔
2. 更新 `追踪/时间线.md` — 记录事件时序
3. 更新 `追踪/角色状态.md` — 更新角色状态 + 性格锚点（如有变化）
4. 更新 `追踪/物品.md` — 物品位置/状态变化
5. 更新 `追踪/环境.md` — 季节/天气/场景
6. 更新 `追踪/重复语句.md` — 记录重复语句
7. 更新 `追踪/上下文.md` — 进度摘要
8. 运行质量门禁：`node skills/_shared/scripts/quality-gate.js <章节文件>`

**质量门禁规则**：退出码 2（阻断）时**不得标记任务完成**，必须修复后重新运行。退出码 0 = 全部通过，1 = 有警告（可继续），2 = 有阻断项（必须修复）。

门禁自动检查：禁用词、一致性（物品/环境/角色/时间线）、伏笔逾期、字数达标。

### 跨会话恢复规则

新会话开始时，必须先读取：
1. `追踪/上下文.md` — 上次进度
2. `追踪/角色状态.md` — 角色当前状态（含性格锚点）
3. `追踪/伏笔.md` — 待回收伏笔
4. 检查 memory 中是否有 in_progress 的任务 → 有则从断点继续

### 性格一致性规则

写对话和行为描写前，必须检查角色的"性格锚点"（在 `追踪/角色状态.md` 中）。不得让角色说出/做出违背锚点的事，除非有充分铺垫。

### 一级禁用词（写正文时必查，命中即替换）

不禁、竟然、居然、事实上、实际上、显而易见、毫无疑问、可想而知、不言而喻、与此同时、值得注意的是、需要指出的是、不可否认、嘴角勾起、嘴角上扬、嘴角微扬、眼中闪过、眼底闪过、目光中闪过、深吸一口气、长舒一口气、吐出一口浊气、缓缓开口、淡淡说道、轻声说道、仿佛、宛如、恰似、犹如、值得一提、不得不说、总而言之

### 重复语句黑名单（写正文前必读）

**写正文前必须加载 `追踪/重复语句.md`**，黑名单中的语句禁止再次使用。

**一致性检测时必须记录重复语句**：
- 检测到重复语句 → 追加到 `追踪/重复语句.md`
- 包含：重复内容、出现位置、重复次数、建议替代

**流程**：
```
写之前：读取追踪/重复语句.md → 加载黑名单 → 写正文时避开
写之后：一致性检测 → 发现重复 → 记录到追踪/重复语句.md
```

### 写作铁律（不可违反）

1. 写正文前必须用 Read 工具读细纲，不得凭记忆写
2. 续写前必须用 Read 工具读上一章正文，不得凭记忆接
3. 写对话前必须查角色性格锚点（`追踪/角色状态.md`）
4. 参考文档标记"必读"的必须实际用 Read 工具加载，不得跳过
5. 字数未达标（< 细纲目标 90%）不得结束本章

### Git Hooks 安装

在写作项目中安装 hooks（仅需一次）：

**macOS / Linux：**
```bash
cp .githooks/* .git/hooks/
chmod +x .git/hooks/*
```

**Windows (PowerShell)：**
```powershell
Copy-Item .githooks\* .git\hooks\ -Force
```
