# 网文写作工具集 - 使用指南

> MiMo Code 网文写作全流程 skill 集合

---

## 一、主技能清单

### 🎯 路由入口

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-mimo** | `/story-mimo`、`写网文` | 主入口，根据意图自动路由到具体 skill |

### 📝 写作类

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-long-write-mimo** | `/写长篇`、`续写`、`日更` | 长篇写作，从大纲到正文，子 agent 隔离执行 |
| **story-chapter-write-mimo** | `/chapter-write`、`写第X章` | 单章写作，14 步严格流程，有问题必修 |
| **story-short-write-mimo** | `/写短篇` | 短篇写作，聚焦情绪拉扯与节奏把控 |

### 📊 大纲与进度

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-outline-mimo** | `/outline`、`生成大纲` | 生成全书大纲和卷纲 |
| **story-progress-mimo** | `/progress`、`进度管理` | 生成 5 章细纲 + 整理跨卷追踪 + 故事线 |

### 🔍 扫榜与选题

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-long-scan-mimo** | `/长篇扫榜` | 分析起点、番茄等平台排行榜 |
| **story-short-scan-mimo** | `/短篇扫榜` | 分析知乎盐言、七猫等短篇平台 |
| **story-scan-mimo** | `/扫榜` | 通用扫榜入口 |

### 📖 拆文分析

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-long-analyze-mimo** | `/长篇拆文` | 深度拆解爆款长篇小说 |
| **story-short-analyze-mimo** | `/短篇拆文` | 拆解短篇小说的故事核、结构、反转 |

### ✅ 质量检查

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **quality-mimo** | `/quality-mimo`、`检查质量` | 综合质量检查（字数+禁用词+一致性+逻辑+设定+跨卷） |
| **story-review-mimo** | `/审稿` | 多视角审稿（结构+人物+文笔+一致性+商业） |
| **audit-mimo** | `/audit-mimo`、`全量审计` | 全量项目审计（角色+物品+环境+时间线+伏笔） |
| **story-deslop-mimo** | `/去AI味` | 检测并清除 AI 写作痕迹 |

### 🎨 辅助工具

| 技能 | 触发词 | 说明 |
|------|--------|------|
| **story-setup-mimo** | `/story-setup-mimo`、`准备写书` | 一键部署写作项目结构 |
| **story-import-mimo** | `/导入小说` | 将已有小说反向解析为标准项目结构 |
| **story-cover-mimo** | `/封面` | 生成小说封面 |
| **story-synopsis-mimo** | `/简介`、`文案` | 生成多平台简介和文案 |
| **story-export-mimo** | `/导出` | 多格式导出（TXT、校对稿等） |
| **goal-mimo** | `/goal` | 设置写作目标，自动循环写作 |
| **project-health-mimo** | `/检查项目` | 检测项目文件是否齐全 |
| **story-session-mimo** | 自动触发 | Session 生命周期管理 |

## 二、两套完整流程

### 流程 A：新书开书

```
┌─────────────────────────────────────────────────────────────┐
│  1. 环境部署                                                  │
│     /story-setup-mimo                                        │
│     → 创建项目目录结构                                        │
│     → 生成 AGENTS.md、配置文件                                │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 扫榜选题（可选）                                          │
│     /story-long-scan-mimo                                    │
│     → 分析平台排行榜                                          │
│     → 生成选题决策.md                                         │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  3. 生成大纲                                                  │
│     /outline                                                 │
│     → 读取设定（世界观、角色、关系、题材）                      │
│     → 生成大纲/大纲.md（全书卷级结构）                         │
│     → 生成大纲/卷纲_第X卷.md（每卷详细规划）                   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  4. 进度管理（生成前 5 章细纲）                                │
│     /progress                                                │
│     → 生成大纲/细纲_第001章.md ~ 细纲_第005章.md              │
│     → 初始化跨卷追踪（跨卷伏笔、角色弧线、卷间过渡）           │
│     → 初始化故事线（索引、主线、交叉点）                       │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  5. 开始写作                                                  │
│     /写长篇  或  /chapter-write                               │
│     → 写第 1 章                                              │
│     → 写第 2 章                                              │
│     → ...                                                    │
│     → 写第 5 章前：自动触发进度管理（生成第 6-10 章细纲）      │
│     → 继续写作...                                            │
└─────────────────────────────────────────────────────────────┘
```

**完整命令序列**：
```bash
/story-setup-mimo          # 1. 部署环境
/story-long-scan-mimo      # 2. 扫榜选题（可选）
/outline                   # 3. 生成大纲
/progress                  # 4. 生成前5章细纲
/写长篇                    # 5. 开始写作
```

### 流程 B：导入现有小说

```
┌─────────────────────────────────────────────────────────────┐
│  1. 导入小说                                                  │
│     /story-import-mimo                                       │
│     → 提供小说文件路径                                        │
│     → 自动检测篇幅（长篇/短篇）                               │
│     → 深度分析（调用拆文管道）                                 │
│     → 迁移为标准项目结构                                      │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  2. 自动生成的内容                                             │
│     ├── 设定/（世界观、角色、势力、关系、题材定位）             │
│     ├── 大纲/（大纲、卷纲、细纲）                              │
│     ├── 正文/（第XXX章_章名.md）                              │
│     ├── 追踪/（伏笔、时间线、角色状态、物品、环境等）           │
│     ├── 故事线/（索引、主线、交叉点）                          │
│     ├── 跨卷追踪/（跨卷伏笔、角色弧线、卷间过渡）              │
│     └── 拆文库/（分析产物）                                   │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  3. 检查与补充                                                │
│     /检查项目                                                │
│     → 检查文件是否齐全                                        │
│     → 补充缺失的设定文件                                      │
│     → 确认大纲和细纲                                          │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│  4. 继续写作                                                  │
│     /写长篇  或  /chapter-write                               │
│     → 从最后一章续写                                          │
│     → 每 5 章自动触发进度管理                                  │
└─────────────────────────────────────────────────────────────┘
```

**完整命令序列**：
```bash
/story-import-mimo         # 1. 导入小说
/检查项目                  # 2. 检查项目完整性
/写长篇                    # 3. 继续写作
```

## 三、写作循环（每章）

```
写第 N 章
    │
    ├── 前置检测：N 是 5 的倍数？
    │   ├── 是 → /progress → 停止等待用户确认
    │   └── 否 → 继续
    │
    ├── 上下文加载（26 项）
    │   ├── 细纲、上一章正文
    │   ├── 追踪文件（8 个）
    │   ├── 设定文件（世界观、金手指、势力、关系、题材、文风）
    │   ├── 跨卷追踪（3 个）
    │   └── 故事线（3 个）
    │
    ├── 正文写作 [子 agent 隔离]
    │   └── 只写作，不检查
    │
    ├── 综合检测+修复 [子 agent 隔离]
    │   ├── 字数达标（BLOCK）
    │   ├── 禁用词+AI腔（BLOCK）
    │   ├── AI标点符号（BLOCK）
    │   ├── 一致性（BLOCK）
    │   ├── 设定校验（BLOCK）
    │   ├── 章内逻辑性（WARN）
    │   ├── 跨章节检查（WARN）
    │   └── 跨卷一致性（WARN）
    │
    └── 追踪更新（10 个文件）
        ├── 追踪（7 个）
        └── 故事线（3 个）
```

## 五、防偷懒机制

| 机制 | 说明 |
|------|------|
| **子 agent 隔离** | 写作、检测、修复由独立子 agent 执行，上下文隔离 |
| **守卫脚本** | 每步执行前后运行 `workflow-guard.js` 验证 |
| **文件传递** | Agent 间通过 `.workflow/` 目录下的 JSON 文件通信 |
| **有问题必修** | 检测到任何 WARN 或 BLOCK 都必须修复 |
| **强制加载** | 设定、跨卷追踪、故事线必须加载到上下文 |
